§2. 요구사항 + 비목표
#요구
R1설치가 끝나 설치된 OS 가 대상 디스크로 처음 부팅하면 서버에 완료를 한 번 보고한다
R2보고를 받으면 열린 행을 SUCCEEDED 로 닫고 다음 소유 phase 로 넘기거나 종단한다
R3성공 때도 서빙 토큰을 회수하고 설치 트리 보유를 반납한다(b-4-2 에서 넘어옴)
R4성공한 설치가 스윕 INSTALL_TIMEOUT 으로 닫히지 않는다(b-4-2 잔존 비대칭 해소)
R5 개정 1로그인 배너에 프로비저닝 대상 서버(기대 시스템 UUID · 이 기계 UUID · 일치 여부 · 시리얼 · 서버 상세 URL)를 보이고, 보고가 끝나면 지운다(b-3 Q1)
R6설치 디스크 · 대상 서버를 사후 확증해 사실로 남긴다(실패 전환 없음)
R7서버 상세 프로비저닝 탭 OS 설치 카드에 RHEL 완료 상태와 설치 결과를 보인다
R8중복 보고는 200 no-op(멱등). Windows 동작 · 스크립트 · URL · JSON 불변
R9 개정 1보고가 끝나면(성공 · 서버 거절 · 부팅 5 회 포기) 게스트에 심은 파일을 모두 지운다. 남는 것은 journal 과 anaconda 기본 파일(토큰은 가림)뿐
R10 개정 1첫 부팅 보고가 부팅 완료를 붙잡지 않고, 실패해도 failed 유닛으로 남지 않는다(Type=simple · 소진해도 exit 0, D-16)
비 목표 (어디로) :
  • OS 후처리 설정 적용(SELinux · 서비스 · 추가 패키지) → E4-1-b-7
  • 사용자 %pre · %post 쉘 스크립트 → 만들지 않음(11-19 결정)
  • Ubuntu 설치 · 완료 보고 → E4-1-b 밖 Ubuntu 실행 슬라이스
  • 실패 뒤 늦게 온 보고로 실패를 되살리기 → 하지 않음(D-13)
  • 실기 검증 → RHEL 전체 CP7 일괄(b-7 뒤)
  • DB 변경 · DDL · 새 env 키 없음
