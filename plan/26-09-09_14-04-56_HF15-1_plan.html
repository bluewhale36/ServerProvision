§2. 요구사항 (확정) + 비목표
  1. 개시부터 OS 설치 착수(wimboot 서빙) 직전까지는 어떤 경로의 재부팅이든 다음 부팅이 PXE 여야 한다 — 에이전트 reboot · BMC 리셋 · 설정 적용의 내부 재시작 전부.
  2. 원하는 무장 상태는 진행 상태의 함수 하나(ProvisioningProgress.isPxeGuaranteeWindow())로만 정한다. 사이트별 명시 호출을 늘리지 않는다.
  3. 창 밖(미개시 · 실패 · 종단 · 회수 · 설치 착수 뒤)에서는 무장을 푼다 — 설치한 OS 가 다시 PXE 로 돌아가면 안 된다.
  4. 설정 phase 의 복귀 증거는 /boot 도착 시각으로 바꾼다 — 체크인 폴링과 컬럼을 분리한다.
  5. 재시도 뒤 네트워크 부팅을 한 번의 조작으로 할 수 있게 한다 (BMC 가 검출된 서버에만 노출).
비 목표 :
  • 게스트(진단 리눅스)에 BMC 자격증명을 주지 않는다 — 대안 C 탈락 사유이자 이 슬라이스의 경계.
  • Windows 설치 중 재PXE 정책(E4-1-a-3 K1)은 무변경 — 창이 서빙 시점에 닫히므로 설치 중 재부팅은 Once 시절과 동일하다.
  • BMC 주소 갱신 경로 · 예약 IP 관리는 다루지 않는다(BMC 주소는 진단이 한 번 읽은 스냅샷이라는 기존 제약 유지).
  • 기본 [재시도] 는 전원 중립을 유지한다 — 네트워크 부팅은 별도 액션으로 분리한다.

§4. 도메인 모델 (SSOT)

판정 SSOT — ProvisioningProgress.isPxeGuaranteeWindow()

public boolean isPxeGuaranteeWindow() {
    if (!isStarted() || isFailed() || isCompleted()) return false;
    boolean osInstallServed = currentStep == ProvisioningPhaseStep.OS_INSTALLING
            && motion == ProvisioningMotion.STEP_RUNNING;
    return !osInstallServed;
}

실패는 창 밖이다 — 재시도가 창을 다시 연다. 회수 여부는 GuestServer 소유라 조정자가 합성한다 (server.getDecommissionedAt() == null && progress.isPxeGuaranteeWindow()).

D1 — PXE 보장 방식 (채택 B)

안요지판정
A 사이트별 명시 호출종단 · 실패 · 회수 · 설치 착수마다 해제, 개시 · 재시도에서 무장탈락 창을 닫는 지점이 실행기 · 워커 · 명령 서비스에 흩어져 있고, F-2b 가 바로 "빠진 경로" 사고였다

리스크 · 잔존

  • BMC 가 굽기 직후 재기동 중이면 조정이 지연된다 — 다음 상태 변화에서 재시도한다.
