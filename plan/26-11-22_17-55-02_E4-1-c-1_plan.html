§1. 현재 상태 (2026-11-22)
Ubuntu 설치는 ISO 를 풀지 않는다. ISO 에서 커널 · initrd · 판별 파일 셋만 꺼내고, ISO 파일은 등록 경로 그대로 토큰 주소로 내준다. 꺼낸 파일의 수명은 RHEL 작업 트리 관리자(E4-1-b-1)를 그대로 쓴다.

§2. 요구 + 비목표
  • R1 등록 Ubuntu ISO(파일)에서 casper/vmlinuz · casper/initrd 만 꺼내 서빙한다. ISO 전체를 풀지 않는다(토론 Q1).
  • R2 ISO 파일 자체를 토큰 주소로 서빙한다. 주소는 .iso 로 끝난다(Q1, casper 1.434).
  • R3 꺼낸 파일의 수명(확보 · 보유자 · 유예 회수 · 기동 정리 · 동시 확보 한 번)은 InstallTreeManager 를 그대로 쓴다(Q1, CLAUDE.md 중복 금지).
  • R4 Ubuntu Server amd64 ISO 인지 판별하고 배포판 · 버전을 읽는다. 아니면 확보 실패 사유로 닫는다(Q1 · Q3).
  • R5 디렉터리 · http(s) 로 등록된 ISO 는 Ubuntu 설치에 못 쓴다(ISO 파일이 있어야 url= 로 내줄 수 있다). 추출을 시도하지 않고 즉시 사유(Q1).
  • R6 RHEL 동작은 바뀌지 않는다(기존 테스트 · 시나리오 하네스 그대로 통과).

J1 installtree/enums/InstallMediaLayout.java 새

/**
 * 설치 매체를 작업 트리에 어떤 모양으로 꺼내는가. 계열마다 다른 다섯 가지(꺼낼 범위, 필요 공간, 판별, 판별 실패 사유,
 * 디렉터리 등록 허용)를 상수가 맡고, 수명 관리(InstallTreeManager)는 계열을 모른다.
 */
public enum InstallMediaLayout {

    /** RHEL 계열: anaconda 가 패키지 저장소를 파일 단위로 읽으므로 ISO 전체를 푼다(E4-1-b-1). */
    RHEL_TREE("images/pxeboot/vmlinuz", "images/pxeboot/initrd.img", TreeFailureReason.NOT_RHEL_TREE) {
        @Override
        public void extract(IsoPreparationService iso, Path isoFile, Path staging) {
            iso.extractInto(isoFile, staging);
        }

        @Override
        public long requiredSpace(long isoBytes) {
            return (long) (isoBytes * WHOLE_HEADROOM);
        }

        @Override
        public Optional<TreeRelease> inspect(Path root) {
            return RhelTreeCheck.inspect(root, kernel(), initrd());
        }

        @Override
        public Optional<TreeFailureReason> directorySourceRefusal() {
            return Optional.empty();   // 마운트해 둔 디렉터리는 그대로 트리로 쓴다(b-1 D-8)
        }
    },

    /** Ubuntu Server: casper 가 ISO 파일을 통째로 받아 loop 마운트하므로 부팅에 필요한 둘과 판별 파일만 꺼낸다(E4-1-c-1). */
    UBUNTU_LIVE_SERVER("casper/vmlinuz", "casper/initrd", TreeFailureReason.NOT_UBUNTU_SERVER_ISO) {
        @Override
        public void extract(IsoPreparationService iso, Path isoFile, Path staging) {
            iso.extractMembers(isoFile, staging, List.of(kernel(), initrd(), UbuntuDiskInfo.FILE));
        }

        @Override
        public long requiredSpace(long isoBytes) {
            return MEMBER_SPACE;
        }

        @Override
        public Optional<TreeRelease> inspect(Path root) {
            if (!Files.isRegularFile(root.resolve(kernel())) || !Files.isRegularFile(root.resolve(initrd()))) {
                return Optional.empty();
            }
            return UbuntuDiskInfo.read(root).filter(UbuntuDiskInfo::installable).map(UbuntuDiskInfo::release);
        }

        @Override
        public Optional<TreeFailureReason> directorySourceRefusal() {
            return Optional.of(TreeFailureReason.DIRECTORY_ISO_UNSUPPORTED);   // url= 로 내줄 ISO 파일이 없다
        }
    };

    static final double WHOLE_HEADROOM = 1.2;
    /** 커널 · initrd 둘(실 ISO 기준 수십 ~ 200 MB)과 여유. */
    static final long MEMBER_SPACE = 512L * 1024 * 1024;

    private final String kernel;
    private final String initrd;
    private final TreeFailureReason notRecognized;

    public abstract void extract(IsoPreparationService iso, Path isoFile, Path staging);
    public abstract long requiredSpace(long isoBytes);
    public abstract Optional<TreeRelease> inspect(Path root);
    public abstract Optional<TreeFailureReason> directorySourceRefusal();
    // 생성자 · kernel() · initrd() · notRecognized() 생략
}

J2 InstallTreeExtractor.extractNow 수정 (바뀐 줄만 보이는 꼴)

TreeAcquisition extractNow(long isoId, Path isoFile, InstallMediaLayout layout) {
    Path staging = null;
    try {
        long required = layout.requiredSpace(Files.size(isoFile));
        if (store.usableSpace() < required) {
            return TreeAcquisition.failed(TreeFailureReason.NOT_ENOUGH_SPACE);
        }
        staging = store.newStagingDir();
        layout.extract(isoPreparationService, isoFile, staging);
        Optional<TreeRelease> release = layout.inspect(staging);
        if (release.isEmpty()) {
            return TreeAcquisition.failed(layout.notRecognized());
        }
        Path published = store.publish(staging, isoId);
        staging = null;
        return TreeAcquisition.ready(new InstallTree(published, release.get(), isoFile));
    } catch (IOException | ExtractionFailedException e) {
        return TreeAcquisition.failed(TreeFailureReason.EXTRACTION_FAILED);
    } finally {
        if (staging != null) {
            store.delete(staging);
        }
    }
}

J3 IsoPreparationService.extractMembers 새

/**
 * ISO 에서 지정한 파일만 꺼낸다(E4-1-c-1). ISO 에 없는 이름은 건너뛴다: 없는 파일은 호출자의 판별이 "그 계열 ISO 가
 * 아님" 으로 닫는다. 지정한 파일이 모두 꺼내졌는데 도구가 실패했으면 손상으로 보고 예외를 던진다.
 */
public void extractMembers(Path isoFile, Path targetDir, List<String> members) {
    boolean toolSucceeded = runMembers(isoFile, targetDir, members);   // bsdtar 먼저, 없으면 7z
    boolean allPresent = members.stream().allMatch(m -> Files.isRegularFile(targetDir.resolve(m)));
    if (!toolSucceeded && allPresent) {
        throw new ExtractionFailedException("ISO 에서 파일을 꺼내지 못했습니다: " + isoFile);
    }
}

/**
 * Ubuntu ISO 의 {@code .disk/info} 첫 줄. live-server ISO 는
 * "Ubuntu-Server 24.04.1 LTS \"Noble Numbat\" - Release amd64 (20240827)" 꼴이다.
 * 배포판 이름은 OS 카탈로그와 같은 "Ubuntu" 로 담아, 버전 대조를 RHEL 과 같은 규칙(TreeInfo.matches)에 맡긴다.
 */
public record UbuntuDiskInfo(String version, String arch) {

    public static final String FILE = ".disk/info";
    private static final Pattern SERVER = Pattern.compile("^Ubuntu-Server (\\d+\\.\\d+(?:\\.\\d+)?)\\b.*\\b(amd64|arm64|ppc64el|s390x|riscv64)\\b");
    private static final String INSTALLABLE_ARCH = "amd64";

    public static Optional<UbuntuDiskInfo> read(Path root) { … }   // 첫 줄을 SERVER 로 해석, 아니면 empty(desktop "Ubuntu 24.04…" 포함)

    public boolean installable() {
        return INSTALLABLE_ARCH.equals(arch);
    }

    public TreeRelease release() {
        return new TreeRelease(OSName.UBUNTU.getDisplayName(), version);
    }
}
