§2. 요구사항 (확정) + 비목표

RHEL 정의서가 OS 설치 단계에 이르면 등록 ISO 로 무인 설치하고, 첫 부팅을 보고받아 다음 단계로 넘긴다.

#요구
R1RHEL 정의서가 OS_INSTALLING 에 이르면 설치가 시작된다
R2설치 원본은 등록 ISO 에서 앱이 준비
R3kickstart 를 정의서대로 생성(비밀번호 해시)
R4OS 영역 볼륨에 설치

R6Rocky 8 · 9 · 10
R7Windows 동작 불변
R8정의서 화면에서 RHEL 계열 선택 가능(Ubuntu 는 계속 막힘)
비 목표 :
  • Ubuntu(autoinstall)
  • OS 설정 phase(RHELOSSettingRequest)
  • 드라이버
  • CentOS 7
  • BIOS(레거시) 부팅
  • 부트 순서 조작(HF24)
  • 설치 원본 서빙의 외부 웹 서버화

D-1 OS 설치 phase 분기OsInstallingExecutor(phase 실행기 1)가 OS 계열별 OsFamilyInstaller(SPI: Windows · RHEL)에 위임. 기존 WindowsInstallingExecutor 본문은 WindowsInstaller 로 이름만 옮김(동작 불변)① registry 키를 (phase, 계열)로

③ phase 는 정의서 계획 계약이라 파급 큼
D-2 설치 원본등록 ISO 를 7z · bsdtar 로 tree-root/{isoId} 에 한 번 풀어 두고 토큰 경로로 정적 서빙① 서빙 때마다 마운트
② 임시 준비 후 복사

D-4 kickstartKickstartRenderer 가 정의서 · 대상 디스크 · 버전 · 보고 URL 로 렌더. 비밀번호 Sha2Crypt.sha512Crypt(commons-codec 의존성 1 추가), isPasswordEncrypted 면 그대로 --iscrypted. root 없으면 rootpw --lock평문 --plaintext사용자 결정으로 탈락
D-5 버전OS 메타(ROCKY_LINUX + 버전 8 · 9 · 10)로 판정. 버전별 차이는 enum RhelRelease 상수 메서드(allowSshRoot 지원 = 10). CentOS · 그 밖 = readiness 차단버전마다 렌더러 클래스차이가 작아 과분리
D-6 디스크OS 영역 볼륨 → RAID 인벤토리 WWN → ignoredisk --only-use=disk/by-id/wwn-0x… · clearpart --drives= · part --ondisk=. 볼륨 찾기는 Windows 와 공통부(OsVolumeLocator)로 추출, 출력만 계열별. CONFIDENT / DEFERRED / BLOCKED 규칙은 Windows 와 같게디스크 이름(sda)열거 순서가 바뀐다(실기 4호 O-3)
D-7 완료 보고설치 뒤 첫 부팅에서 systemd oneshot 유닛이 보고(부팅 가능까지 증명, Windows FirstLogonCommands 와 같은 의미). %post 가 유닛을 심고, 성공하면 스스로 비활성%post 에서 보고설치 완료만 증명, 디스크 부팅 실패를 못 잡는다
D-8 원장 · 시한RhelInstallLedger(ORIGIN rhel-install) · RhelInstallTimeoutPolicy(provision.rhel-install.*). 두 스위퍼 모두 자기 origin 행만 집게 수정(Windows 스위퍼가 RHEL 을 실패 처리하는 결함 예방). WindowsInstallLedger.isWindowsInstallRow(origin 판독)가 이미 있어 스위퍼 · latestRunning 의 origin 대조에 재사용공용 원장 하나사유 코드 · meta 가 계열마다 다름
D-9 정의서 화면OsInstallTargetPolicy 가 RHEL 계열(Rocky 8 · 9 · 10)을 허용. RHEL 계열은 정의서 단계에서 설치 트리 준비 여부를 보지 않는다(실행 준비도가 맡음). LINUX_BLOCK_REASON 은 Debian 계열 전용 문구로: "Ubuntu 계열 설치는 추후 지원 예정입니다."——
D-10 슬라이스하나로 진행(긴급). 단계 순서: 트리 준비 → 분기 · 토큰 · 서빙 → kickstart → 완료 보고둘로 분할(트리 / 설치기)검증 줄기는 갈리지만 일정상 하나
kickstart : 필수 지시어(lang · keyboard · timezone · 인증 · 파티션 · bootloader)를 늘 넣는다. 1차 구현과 같은 의미로 text · lang en_US.UTF-8 · keyboard --xlayouts='us' · network --bootproto=dhcp --activate · firstboot --disable · bootloader · reboot 을 더한다. bootloader --append="crashkernel=auto" 는 넣지 않는다(kdump 는 %addon 이 맡음).
