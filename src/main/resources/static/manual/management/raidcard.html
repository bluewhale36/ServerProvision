RAID 카드

RAID 카드 자원은 서버에 장착된 RAID 카드의 사양 정보입니다. 세팅 정의서의 RAID 구성 단계에서 카드를 지정하면, PXE 서버가 그 사양으로 만들 수 있는 구성을 판정하고 실행할 때 실제 카드와 대조합니다. RAID 카드는 메인보드에 속하지 않는 독립 자원이며 파일이 없습니다.

프로비저닝에서의 용도

  • 정의서의 RAID 구성 단계는 RAID 카드를 이용한 구성만 지원합니다. 메인보드에 내장된 RAID 는 지원하지 않습니다.
  • 정의서 작성 화면은 카드의 지원 RAID 레벨, 캐시 용량, 칩 계열로 디스크 묶음 표의 선택지를 정합니다. 카드가 지원하지 않는 레벨은 고를 수 없습니다. 정의서에서 고를 수 있는 레벨은 RAID0, RAID1, RAID5, RAID6, RAID10 다섯 가지입니다.
  • 실행할 때 진단 리눅스가 감지한 카드의 PCI Subsystem ID 와 정의서가 지정한 카드의 값을 비교합니다. 다르거나 카드가 감지되지 않으면 RAID 구성 단계가 실패합니다.
  • 정의서를 서버에 할당할 때도 같은 비교를 합니다. 카드가 맞지 않는 정의서는 할당 창에서 잠김으로 표시됩니다. 서버의 RAID 카드 정보를 아직 수집하지 않았거나, 카드의 PCI Subsystem ID 가 미확인이거나, 정의서가 지정한 카드가 영구 삭제됐으면 대조 전으로 표시됩니다.
주의

PCI Subsystem ID 가 비어 있는(미확인) 카드는 실물 대조를 건너뜁니다. 다른 카드가 장착된 서버에서도 RAID 구성 단계가 진행될 수 있으므로, 카드를 정의서에 쓰기 전에 PCI Subsystem ID 를 확정해 둡니다.

화면 구성

사이드바에서 자원 관리RAID 카드 를 엽니다. 왼쪽 열에서 제조사를 고르면 가운데 열에 카드가 나타나고, 카드를 고르면 오른쪽 열에 상세가 나타납니다.

상세에는 ID, 제조사, 모델명, 지원 RAID 레벨, 캐시, PCI Subsystem ID, 설명, 상태, 사용 중단 권고가 표시됩니다. 칩 계열은 상세에 표시되지 않고 수정 화면에서 확인할 수 있습니다.

PCI Subsystem ID 확정

PCI Subsystem ID 를 비워 두고 등록한 카드는 상세에 미확인 으로 표시됩니다. 이 카드를 지정한 정의서가 할당된 서버가 진단을 마치면, 그 서버가 감지한 카드의 값이 상세의 관측 영역에 나타납니다.

같은 카드가 이미 있을 때

제조사와 모델명이 같은 카드가 삭제되지 않았고 Deprecated 도 아닌 상태로 있으면 모델명 칸 아래에 "이미 등록된 RAID 카드입니다. GIGABYTE CRA3338" 처럼 오류가 표시됩니다. 휴지통이나 Deprecated 상태로 있으면 중복 확인 창이 열리며, 처리 방법은 같은 자원이 이미 있을 때를 따릅니다.

정보 수정

상세의 수정 을 누르면 제조사를 뺀 모든 항목을 바꿀 수 있습니다. 지원 RAID 레벨을 바꾸면 정의서 작성 화면의 카드 판정에도 바로 반영됩니다. 제조사를 바꾸려면 삭제하고 다시 등록합니다.

칩 계열이 MPT IR 인 카드의 수정 화면을 열면 등록할 수 없는 레벨 칸이 잠깁니다. 예전에 이 카드에 RAID5 나 RAID6 을 등록해 두었다면 수정 화면을 여는 순간 그 체크가 풀리고, 저장하면 지원 레벨에서 빠집니다.

상태 변경과 삭제

일반적인 동작은 자원의 상태와 삭제에서 설명합니다. RAID 카드는 하위 자원과 부모가 없으므로 상태 변경이 다른 자원에 퍼지지 않습니다.

  • 비활성화한 카드는 정의서의 RAID 카드 선택지에서 빠집니다. 이미 저장한 정의서를 수정할 때는 카드를 다시 고르거나 RAID 묶음을 비워야 저장됩니다.
  • 같은 제조사와 모델명의 카드가 Deprecated 가 아닌 상태로 휴지통 밖에 있으면 복구할 수 없습니다. 복구하려는 카드가 Deprecated 상태로 삭제된 것이라면 막히지 않습니다.
  • 휴지통에서 자동으로 영구 삭제되지 않고 보존 기간 연장 대상도 아닙니다. 필요 없으면 직접 영구 삭제합니다.
  • Deprecated 해제는 확인 창 없이 바로 적용됩니다.
  • 영구 삭제할 때 입력할 자원명은 제조사와 모델명입니다(예: GIGABYTE CRA3338).
