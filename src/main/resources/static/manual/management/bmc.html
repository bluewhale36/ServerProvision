BMC 펌웨어

BMC 펌웨어는 세팅 정의서의 펌웨어 업데이트 단계에서 서버의 BMC 에 기록할 이미지 파일입니다. 화면 구성, 등록 절차, 순위는 BIOS 펌웨어와 같습니다.

프로비저닝에서의 용도

정의서의 펌웨어 업데이트 단계에서 업데이트할 BMC 버전을 고릅니다. 최신 버전은 BIOS 와 같이 순위가 가장 높은 활성 펌웨어입니다.

  • BMC 기록의 기본 제한 시간은 30분입니다. 기록이 끝나면 BMC 가 스스로 다시 시작하므로 5분에서 10분 동안 BMC 에 접속할 수 없는 것이 정상입니다. 그동안 BMC 웹에서 전원 조작이나 재시작을 하지 않습니다. 이 구간의 수동 조작은 기록 실패 판정의 원인이 됩니다.
  • 반영 확인은 BMC 가 보고하는 자기 펌웨어 버전과 등록한 버전을 비교합니다. 버전 칸에는 BMC 웹 화면에 보이는 BMC 펌웨어 버전 표기를 그대로 적습니다.
  • BIOS 와 BMC 를 함께 업데이트하면 BIOS, BMC 순서로 하나씩 기록하고, 둘 다 기록한 뒤 BIOS, BMC 순서로 반영을 확인합니다. BIOS 확인이 실패하면 BMC 는 확인하지 않습니다.

화면

사이드바에서 자원 관리BMC 를 엽니다. 화면 제목은 "BMC 펌웨어 관리" 이고, 구성은 BIOS 펌웨어 화면과 같습니다. 등록은 가운데 열 아래의 + BMC 등록, 메인보드 페이지의 BMC 등록, 오른쪽 위의 + 신규 BMC 등록 중 하나로 시작합니다.
