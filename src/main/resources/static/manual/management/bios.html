BIOS 펌웨어

BIOS 펌웨어는 세팅 정의서의 펌웨어 업데이트 단계에서 서버에 기록할 BIOS 이미지 파일입니다. BIOS 펌웨어는 반드시 메인보드 모델 하나에 속하므로, 메인보드 모델을 먼저 등록해야 합니다.

프로비저닝에서의 용도

정의서의 펌웨어 업데이트 단계에서 업데이트할 BIOS 버전을 고릅니다. 기본값인 최신 버전은 실행할 때 그 서버의 보드에 등록된 BIOS 펌웨어 중 순위가 가장 높은 활성 펌웨어를 뜻합니다. 버전 숫자를 비교하지 않으므로 순위를 올바르게 정해 두어야 합니다.

  • PXE 서버는 서버의 BMC 에 펌웨어 파일을 내려받게 해서 기록합니다(Redfish 업데이트). BIOS 기록의 기본 제한 시간은 15분입니다.
  • 서버의 BIOS 가 이미 같은 버전이어도 다시 기록합니다. 같은 버전 번호의 수정 이미지(로고 변경본 등)를 쓸 수 있도록 하기 위해서입니다.
  • 기록이 끝나면 BMC 가 보고하는 BIOS 버전과 등록한 버전을 비교해 반영을 확인합니다. 앞뒤 공백과 대소문자만 무시하고 비교하므로, 버전 칸에는 BMC 웹 화면에 보이는 BIOS 버전 표기를 그대로 적습니다. 다르면 그 업데이트는 실패로 기록됩니다.
  • 순위 1위인 활성 펌웨어의 파일이 사라졌거나 쓸 수 있는 펌웨어가 없으면 2위로 내려가지 않고 BIOS 업데이트를 건너뜁니다. 정의서에서 특정 버전을 골랐는데 그 펌웨어를 끄거나 삭제한 경우에도 건너뜁니다.
  • 펌웨어의 마커 파일이 없거나 서명이 맞지 않으면, 또는 정의서가 지정한 보드가 서버의 보드와 다르면 건너뛰지 않고 차단합니다.

펌웨어 파일 규칙

펌웨어 하나는 파일 하나이며, 그 파일만 들어 있는 폴더에 둡니다. 등록하면 같은 폴더에 마커 파일 .provision.json 이 함께 기록됩니다. 다른 파일이 함께 있는 폴더나 이미 다른 자원의 마커가 있는 폴더는 거절됩니다.

BIOS 펌웨어 등록

  1. 가운데 열 아래의 + BIOS 등록 을 누릅니다. 메인보드 페이지의 BIOS 등록 으로 시작해도 됩니다. 두 경우 모두 보드가 미리 선택됩니다. 화면 오른쪽 위의 + 신규 BIOS 등록 으로 시작하면 메인보드 모델부터 고릅니다.
  2. 이름을 입력합니다. 화면에서 알아보기 쉬운 이름이며 128자까지 입력할 수 있습니다.
  3. 버전을 입력합니다. BMC 웹 화면에 보이는 BIOS 버전 표기와 같게 적습니다. 같은 메인보드 안에서 버전은 겹칠 수 없습니다.
  4. 펌웨어 파일 경로를 입력하거나 탐색 으로 고릅니다.
  5. 파일을 업로드하려면 펌웨어 파일 업로드 (선택)에서 파일을 고릅니다. 비워 두면 경로에 이미 있는 파일을 그대로 등록합니다.
  6. 필요하면 설명을 입력하고 등록 을 누릅니다. 등록이 끝날 때까지 화면을 떠나지 않습니다. 끝나면 목록으로 돌아가고 새 펌웨어가 선택된 상태로 열립니다.

새로 등록한 펌웨어는 언제나 순위 1위로 들어가고 기존 펌웨어는 한 칸씩 내려갑니다. 예전 버전을 나중에 등록했다면 등록한 뒤 순위를 내립니다.

순위

가운데 열의 위에서 아래 순서가 순위이며, 맨 위가 1위입니다. 펌웨어 업데이트의 최신 버전은 이 순위로 정해집니다.

  1. 가운데 열에서 펌웨어 왼쪽의 ☰ 아이콘을 눌러 원하는 위치로 끌어다 놓습니다.
  2. 놓는 즉시 저장됩니다. latest 표시가 새 순위에 맞게 옮겨집니다.
  • 저장에 실패하면 원래 순서로 돌아가고 "순서 저장에 실패했습니다" 가 잠시 표시됩니다. 화면을 새로 고친 뒤 다시 시도합니다.
  • 조회 조건이 걸려 있거나 삭제된 항목 포함 보기에서는 순위를 바꿀 수 없습니다. 조건을 초기화하면 다시 바꿀 수 있습니다.
  • 삭제된 펌웨어도 순위 자리를 유지하므로 복구하면 원래 위치로 돌아옵니다.

정보 수정

상세의 수정 을 누르면 이름, 버전, 설명을 바꿀 수 있습니다. 메인보드와 펌웨어 파일은 바꿀 수 없습니다. 파일을 바꾸려면 펌웨어를 삭제하고 다시 등록합니다.

상태 변경과 삭제

일반적인 동작은 자원의 상태와 삭제에서 설명합니다. BIOS 펌웨어에만 해당하는 내용은 다음과 같습니다.

  • 부모 메인보드가 비활성이거나 삭제된 동안에는 활성화할 수 없고, 메인보드가 Deprecated 이거나 삭제된 동안에는 Deprecated 를 해제할 수 없습니다.
  • 비활성화한 펌웨어는 최신 버전 후보와 정의서 선택지에서 빠집니다.
  • 같은 보드에 같은 버전의 펌웨어가 살아 있으면 복구할 수 없습니다.
  • 영구 삭제할 때 입력할 자원명은 펌웨어의 이름입니다. 펌웨어 폴더는 삭제할 때 이미 휴지통 폴더로 옮겨지며, 휴지통 화면에서 영구 삭제해야 휴지통 폴더의 파일까지 지워집니다.
