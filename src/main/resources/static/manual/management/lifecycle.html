자원의 상태와 삭제

OS 버전, ISO, 메인보드, BIOS 펌웨어, BMC 펌웨어, RAID 카드, 드라이버와 유틸리티는 모두 같은 방식으로 상태를 바꾸고 삭제합니다. 자원마다 다른 점은 각 자원 페이지에 있습니다.

두 가지 상태

자원 상세의 상태 행은 활성 여부를, 사용 중단 권고 행은 사용 중단 권고 여부를 보여 줍니다. 두 상태는 서로 독립입니다. 사용 중단을 권고해도 자원은 활성 상태 그대로이고, 비활성화해도 사용 중단 권고는 바뀌지 않습니다.

상태배지프로비저닝에 미치는 영향
활성 여부 활성 또는 비활성 비활성 자원은 세팅 정의서의 선택지에서 제외. 펌웨어 업데이트가 고르는 펌웨어 후보에서도 제외

활성과 비활성

상세의 상태 행에서 비활성화 또는 활성화 를 누르면 확인 창 없이 바로 바뀝니다.

부모 자원을 비활성화하면 그 아래 자원도 모두 비활성으로 보입니다. 부모는 메인보드 모델(BIOS 펌웨어, BMC 펌웨어, 보드 전용 드라이버와 유틸리티의 부모)과 OS 버전(ISO 의 부모)입니다. 부모를 다시 활성화하면 운영자가 직접 비활성으로 꺼 둔 하위 자원을 뺀 나머지가 활성으로 돌아옵니다. 화면은 부모 때문에 비활성인 자원과 직접 비활성화한 자원을 똑같이 비활성 으로 보여 주므로, 부모를 활성화한 뒤에도 비활성으로 남은 하위 자원은 운영자가 직접 꺼 둔 것입니다.

부모가 비활성이거나 삭제된 상태에서는 하위 자원의 활성화 버튼이 눌리지 않습니다. 버튼에 마우스를 올리면 이유가 표시됩니다. 부모를 먼저 활성화하거나 복구합니다.

주의

세팅 정의서가 쓰고 있는 자원을 비활성화하거나 삭제해도 자원 화면은 경고하지 않습니다. 정의서 상세에 표시가 붙는 경우는 두 가지뿐입니다. OS 설치 단계의 ISO 를 끄거나 삭제하면 "실행 불가", 펌웨어 업데이트 단계에서 최신 버전으로 지정한 보드의 펌웨어가 모두 꺼지면 "실행 시 생략 가능" 이 붙습니다. 특정 버전으로 고른 펌웨어를 끄거나 삭제하면 정의서 화면에는 표시가 없고 실행할 때 그 업데이트를 건너뜁니다. 자원을 끄기 전에 그 자원을 쓰는 정의서가 있는지 확인합니다.

사용 중단 권고

더 이상 새로 쓰지 않기를 권하는 자원에 사용 중단을 권고합니다. 상세의 사용 중단 권고 행에서 사용 중단 권고 를 누르면 확인 창이 열리고, 사용 중단 권고 를 한 번 더 누르면 적용됩니다. 해제는 사용 중단 권고 해제 로 합니다. 해제의 확인 창은 OS 버전, ISO, BIOS 펌웨어, BMC 펌웨어에만 있고, 다른 자원은 누르면 바로 적용됩니다.

  • 부모에 사용 중단을 권고하면 하위 자원도 모두 사용 중단으로 보입니다. 부모의 권고를 해제하면 하위 자원 중 운영자가 직접 권고한 것은 그대로 남습니다.
  • 부모가 사용 중단 권고 상태이거나 삭제된 상태에서는 하위 자원만 따로 해제할 수 없습니다.
  • 목록의 가운데 열에서 사용 중단 권고 자원 옆에는 노란 점이 표시됩니다.

세팅 정의서를 작성할 때 사용 중단이 권고된 자원을 고르면 "사용 중단 권고 자원" 확인 창이 열립니다. 그래도 적용 을 누르면 선택이 유지되고, 다른 방법으로 창을 닫으면 이전 선택으로 돌아갑니다. 저장한 정의서의 상세에는 그 단계에 "사용 중단 권고 자원 사용" 배지가 붙습니다.

삭제

상세의 삭제 를 누르면 "자원 삭제" 확인 창이 열리고, 삭제 를 한 번 더 누르면 자원이 휴지통으로 옮겨집니다. 삭제는 되돌릴 수 있습니다.

  • 파일이 있는 자원은 PXE 서버의 휴지통 폴더로 옮겨집니다. ISO 는 파일이, BIOS 펌웨어와 BMC 펌웨어, 드라이버와 유틸리티는 그 파일이 든 폴더 전체가 옮겨지고, 원래 위치의 마커 파일은 지워집니다. 마커 파일은 PXE 서버가 등록한 파일임을 증명하는 서명 파일입니다.
  • 파일이 없는 자원(OS 버전, 메인보드, RAID 카드)은 기록만 휴지통 상태가 됩니다. 그 아래에 하위 자원이 있으면 함께 휴지통으로 옮겨집니다.
  • 삭제된 자원은 목록에서 숨겨집니다. 조회 띠에서 삭제된 항목 포함을 켜면 "(삭제)" 표시와 함께 보이고, 상세의 상태 행에는 삭제 배지가 표시됩니다.
주의

서버에 이미 있던 파일을 경로만 지정해 등록한 자원도 삭제하면 그 파일이 휴지통 폴더로 옮겨져 원래 위치에서 사라집니다. 원본 파일을 따로 보관해야 한다면 등록 전에 복사해 둡니다.

파일이 원래 위치에 없을 때

ISO, BIOS 펌웨어, BMC 펌웨어, 드라이버와 유틸리티를 그 화면에서 직접 삭제하려는데 PXE 서버가 추적하는 위치에 파일이 없으면 삭제가 진행되지 않고 "파일을 찾을 수 없습니다" 창이 열립니다. 메인보드를 삭제할 때 하위 펌웨어나 드라이버 중 하나라도 파일이 없으면 이 창 없이 메인보드 삭제 전체가 거절됩니다. 이때는 파일이 없는 하위 자원을 먼저 그 화면에서 직접 삭제합니다.

강제 정리는 휴지통을 거치지 않고, 자원명 입력 확인도 없으며, 감사 기록도 남기지 않습니다. 브라우저 확인 창 한 번으로 기록이 영구 삭제되므로 파일이 실제로 사라졌는지 확인한 뒤에만 고릅니다.

휴지통 보존 기간

ISO, BIOS 펌웨어, BMC 펌웨어, 드라이버와 유틸리티는 휴지통에 들어간 지 기본 30일이 지나면 자동으로 영구 삭제됩니다. 자동 영구 삭제는 매시 정각에 실행되고, 기본 설정에서는 만료 7일 전과 1일 전에 배경 작업 목록에 영구 삭제 예정 알림이 표시됩니다. 이 자원들은 휴지통 화면에서 보존 기간을 연장할 수 있습니다. OS 버전, 메인보드, RAID 카드는 자동으로 지워지지 않고 연장 대상도 아니므로, 필요 없으면 직접 영구 삭제합니다. 자세한 내용은 휴지통에서 설명합니다.

복구

조회 띠에서 삭제된 항목 포함을 켜고 삭제된 자원을 고르면 상세에 복구 버튼이 보입니다. 누르면 "자원 복구" 확인 창이 열립니다. 하위 자원이 있는 자원은 창에서 복구 범위를 고릅니다.

영구 삭제

삭제된 자원의 상세에서 영구 삭제 를 누르면 "자원 영구 삭제" 확인 창이 열립니다. 창의 "정확히 입력해야 할 자원명" 아래에 표시된 이름을 입력칸에 그대로 입력해야 영구 삭제 버튼이 눌립니다. 대소문자와 공백까지 같아야 합니다. 영구 삭제는 되돌릴 수 없습니다.

입력해야 할 자원명은 화면의 자원 이름과 다를 수 있으므로 반드시 창에 표시된 것을 확인합니다.

휴지통 화면에서 하는 영구 삭제도 같은 확인 창을 거칩니다. 자원 화면과 휴지통 화면 어느 쪽에서 영구 삭제해도 휴지통 폴더의 파일이 함께 지워지고 감사 기록이 남습니다. 하위 자원이 남아 있을 때의 규칙은 자원마다 다르므로 각 자원 페이지를 확인합니다.

영구 삭제는 원래 경로에 남은 마커가 그 자원을 가리킬 때만 원래 경로를 지웁니다. 삭제한 뒤 같은 경로에 다른 자원을 등록했다면 그 자원의 파일은 지워지지 않습니다. 마커가 없거나 손상된 경로도 지우지 않습니다. 이렇게 남은 파일은 자동으로 지워지지 않으므로 운영자가 확인해 정리합니다. 휴지통의 30일 자동 영구 삭제도 같은 규칙을 따릅니다.

확인 창을 열어 둔 사이 다른 화면이나 다른 사용자가 그 자원을 영구 삭제했다면, 확인 창의 영구 삭제 를 눌렀을 때 "휴지통에 있는 자원만 영구 삭제할 수 있습니다. 목록을 새로 고친 뒤 다시 확인해야 합니다." 가 표시됩니다. 목록을 새로 고칩니다.

같은 자원이 이미 있을 때

ISO, BIOS 펌웨어, BMC 펌웨어, 드라이버를 등록할 때 같은 자원이 이미 있으면 기존 자원의 상태에 따라 처리가 갈립니다. 같은 자원의 기준과 확인 시점(업로드 전 또는 업로드 뒤)은 자원마다 다르며 각 자원 페이지에서 설명합니다.

OS 버전, 메인보드 모델, RAID 카드는 이 창이 열리지 않습니다. 같은 자원이 휴지통에 있어도 등록되지 않고, 기존 자원의 상태에 맞는 안내가 표시됩니다. 안내와 조치는 OS 버전, 메인보드, RAID 카드 페이지에서 설명합니다.

창에는 휴지통에 있는 같은 자원이 후보로 나열되고, 오른쪽 위에 남은 시간이 표시됩니다. 5분 안에 고르지 않으면 창이 닫히고 처음부터 다시 등록해야 합니다. 창 바깥을 누르면 취소와 같습니다. 파일을 올린 뒤에 열린 창이 만료되면 업로드된 파일이 대상 폴더에 남으므로, 그 폴더를 정리한 뒤 다시 등록합니다.

버튼동작
그래도 등록휴지통의 기존 자원을 그대로 두고 새 자원 등록
기존 영구 삭제 후 등록목록에서 고른 기존 자원을 영구 삭제하고 새 자원 등록. 휴지통 화면의 영구 삭제와 같이 휴지통 폴더의 파일을 지우고 감사 기록 유지. 후보를 하나 골라야 버튼 활성화, 자원명 입력은 불필요
취소등록 중단. 업로드한 파일이 있으면 정리하고, 이미 있던 파일이나 폴더를 경로로 지정해 등록한 경우에는 그대로 유지

기존 영구 삭제 후 등록 에서 영구 삭제는 끝났는데 새 자원 등록이 실패하면 "기존 자원은 영구 삭제했지만 새 자원 등록에 실패했습니다." 뒤에 실패 사유가 표시됩니다. 기존 자원은 이미 지워졌으므로 사유를 해결한 뒤 다시 등록합니다. 창을 열어 둔 사이 다른 화면에서 후보를 복구했다면 "휴지통에 있는 자원만 영구 삭제할 수 있습니다." 로 거절됩니다.

주의

기존 자원을 다시 쓰려면 새로 등록하지 않고 휴지통에서 복구합니다. 그래도 등록 으로 같은 자원을 하나 더 만들면, 휴지통 밖에 같은 자원이 생기므로 휴지통의 기존 자원은 더 이상 복구할 수 없습니다.

목록 조회 띠

모든 자원 목록 화면 위쪽에 같은 조회 띠가 있습니다. 검색칸에 입력하고 Enter 를 누르면 대소문자를 무시하고 부분 일치로 찾습니다. 옆의 Search 를 누르면 조회 조건 창이 열리고, 창 하단의 검색 을 눌러야 조건이 적용됩니다.

파일 경로 입력

파일이 있는 자원을 등록하거나 수정할 때는 PXE 서버 안의 파일 경로를 입력합니다. 경로 칸 옆의 탐색 을 누르면 탐색 창이 열립니다. 폴더를 누르면 그 안으로 들어가고, 파일을 누르면 그 경로가 입력칸에 들어갑니다. ↑ 상위 로 상위 폴더로 이동합니다.

경로는 PXE 서버 관리자가 정한 허용 영역 안에 있어야 합니다. 탐색 창은 허용 영역 밖으로 올라가지 않습니다. 직접 입력한 경로에 대해서는 다음 오류가 표시될 수 있습니다.

무결성 상태

파일이 있는 자원의 상세에는 무결성 행이 있습니다. 검증 을 누르면 배경 작업으로 서명과 파일 내용을 다시 확인하고, 끝나면 표시가 갱신됩니다. 무결성 상태는 영문으로 표시됩니다.

표시뜻조치
NOT_VERIFIED아직 검증 전필요하면 검증 실행
ORIGINAL등록할 때의 파일 그대로조치 불필요
TAMPERED서명은 유효하나 파일 내용 변경파일을 바꾼 경위 확인, 자원 무결성 점검에서 처리
SIGNATURE_INVALID마커 서명 불일치. 다른 서버에서 옮겨 온 파일이거나 마커 변조자원 무결성 점검에서 처리
MARKER_MISSING마커 파일 부재자원 무결성 점검에서 처리

파일을 옮기거나 마커가 어긋난 자원을 정리하는 방법은 자원 무결성 점검에서 설명합니다.
