BIOS 세팅 템플릿

BIOS 세팅 템플릿은 서버의 BIOS 에 적용할 설정값의 묶음입니다. 템플릿은 메인보드 모델 하나에 속하며, 세팅 정의서의 BIOS 설정 단계에서 고릅니다.

프로비저닝에서의 용도

  • 정의서의 BIOS 설정 단계에서 메인보드를 지정하면 그 보드의 템플릿 1개를 고르고, 자동 감지로 두면 보드마다 템플릿을 1개씩 고를 수 있습니다.
  • 정의서를 서버에 할당하는 순간 고른 템플릿의 값이 복사되어 할당에 고정됩니다. 그 뒤 템플릿을 고쳐도 이미 할당된 서버에는 반영되지 않습니다. 새 값을 쓰려면 개시 전에 다시 할당합니다.
  • 실행할 때는 서버에서 감지된 보드와 같은 보드의 템플릿만 적용합니다. 맞는 템플릿이 없으면 BIOS 설정을 건너뛰고 BMC 표준 설정으로 넘어갑니다.
  • 적용 직전에 서버의 실제 BIOS 버전에 맞는 설정 항목 목록과 템플릿 값을 다시 대조합니다. 허용되지 않는 값이 있으면 BIOS 에 쓰지 않고 그 단계를 실패로 기록합니다. BMC 에서 목록을 받지 못하면 대조 없이 적용하고, 값이 맞지 않으면 BMC 가 거절한 사유로 실패가 기록됩니다.

BIOS 설정 항목 목록

템플릿 편집기는 보드의 BIOS 설정 항목 목록(화면에는 레지스트리로 표시)을 바탕으로 그려집니다. PXE 서버는 이 목록을 다음 순서로 찾아 씁니다.

순서출처화면의 레지스트리 표시
1그 보드의 최신 활성 BIOS 펌웨어와 같은 버전으로 채집한 목록"레지스트리 (BIOS 버전) · (날짜) 채집 · (BMC 주소)"
2그 보드에서 가장 최근에 채집한 목록"레지스트리 최신 채집 (BIOS 버전) · 목표 (버전) 미채집"
3PXE 서버에 준비된 자료 파일"레지스트리 파일 · 버전 미상"

채집은 프로비저닝 중 PXE 서버가 서버의 BMC 에서 실제 BIOS 버전과 그 버전의 설정 항목 목록을 받아 저장하는 것입니다. 펌웨어 업데이트 뒤 반영을 확인할 때와 BIOS 설정을 적용하기 직전에 일어나며, 보드와 BIOS 버전마다 한 번만 받습니다. 그래서 펌웨어 업데이트나 BIOS 설정 단계로 그 보드의 서버를 한 번 프로비저닝하고 나면 목록이 실제 BIOS 에 더 가까워집니다.

템플릿을 만들 수 있는 보드

템플릿은 PXE 서버에 BIOS 자료가 준비된 보드에만 만들 수 있습니다. 기본 설정으로 준비된 보드는 MS03-CE0, MS73-HB1, MS04-CE0, MS74-HB0, MD72-HB3 입니다. 이 보드라도 메인보드 화면에 먼저 등록해야 보드 선택 화면에 나타납니다. 그 밖의 보드는 보드 선택 화면에 흐리게 "카탈로그 미보유" 로 표시되고 고를 수 없습니다. 보드를 추가하려면 PXE 서버 관리자에게 요청합니다. 화면에서 추가하는 기능은 없습니다.

화면 구성

사이드바에서 프로비저닝BIOS 세팅 을 엽니다. 목록 표에는 #(템플릿 ID), 명칭, 대상 보드, 변경 속성 수, 수정일시가 표시됩니다. 명칭에 마우스를 올리면 설명이 보이고, 정의서가 쓰고 있는 템플릿에는 사용 중 이 붙습니다. 행을 누르면 상세가 열립니다. 목록에는 검색과 조회 조건이 없습니다.

템플릿 작성

  1. 새 템플릿 작성 을 누릅니다.
  2. 보드 선택 화면에서 템플릿을 만들 보드 카드의 템플릿 작성 ▶ 을 누릅니다.
  3. 템플릿 명칭을 입력합니다. 필요하면 설명을 입력합니다.
  4. 편집기에서 바꿀 항목을 찾아 값을 바꿉니다. 탐색 방법은 아래 편집기에서 설명합니다.
  5. F4 템플릿 저장 을 누르거나 F4 키를 누릅니다. 저장되면 목록으로 돌아갑니다.

템플릿에는 기본값에서 바꾼 항목만 저장됩니다. 목록의 변경 속성 수가 그 개수입니다. 명칭을 입력하지 않았거나 바꾼 항목이 하나도 없으면 저장 버튼이 눌리지 않고, 마우스를 올리면 이유가 표시됩니다.

명칭 규칙

입력 칸규칙
템플릿 명칭필수 입력, 128자 이하. 보드가 달라도 다른 템플릿과 같은 이름 불가
설명선택 입력, 1024자 이하

같은 명칭이 이미 있으면 "이미 사용 중인 템플릿 명칭입니다" 오류가 화면 위쪽에 표시됩니다.

편집기

편집기는 실제 서버의 BIOS 설정 화면과 같은 구성으로 그려집니다. 항목 이름과 도움말은 BIOS 원문(영문) 그대로입니다. 편집기 머리줄에는 보드 모델명과 BIOS 설정 항목 목록의 출처가 표시됩니다.

영역사용 방법
탭BIOS 의 최상위 메뉴. 눌러서 메뉴 전환
항목 행오른쪽 칸에서 값을 바꾼다. ▶ 가 있는 행은 하위 메뉴로 들어간다. ↻ 표시는 바꾸면 재부팅이 필요한 항목
메뉴 경로하위 메뉴로 들어간 경로. 앞 단계를 눌러 되돌아간다. Esc 키는 한 단계 위로 이동
Item Help항목에 마우스를 올리거나 선택하면 BIOS 도움말과 숫자 항목의 허용 범위 표시
F3 기본값 복원모든 항목을 BIOS 기본값으로 되돌린다. 수정 중이어도 저장값이 아니라 기본값으로 돌아가며 확인 창이 없다
F4 템플릿 저장저장
  • 선택지 항목은 목록에서 고르고, 숫자 항목은 허용 범위와 증분 안에서 입력합니다.
  • 비밀번호 항목과 문자열 항목은 템플릿에 담을 수 없어 편집기에 나오지 않습니다. 읽기 전용 항목은 회색으로 표시되고 저장되지 않습니다.
  • 다른 항목의 값에 따라 행이 숨겨지거나 흐려집니다. 숨겨지거나 흐려진 항목은 저장되지 않습니다.
  • 검색 기능은 없습니다. 탭과 하위 메뉴로 항목을 찾습니다.

상세

상세 머리에는 명칭, 대상 보드, BIOS 설정 항목 목록의 출처가 표시됩니다. 아래에 다음 영역이 있습니다.

영역내용
기본 정보템플릿 ID, 설명, 생성일시, 수정일시
변경 속성BIOS 메뉴 경로별로 묶은 바꾼 항목. 항목마다 기본값과 저장값, 재부팅 필요 표시
레지스트리와 어긋난 저장 속성현재 설정 항목 목록과 맞지 않는 저장값이 있을 때만 표시
Redfish Request Body실행할 때 BMC 로 보낼 요청의 미리보기

레지스트리와 어긋난 저장 속성

상세는 지금 시점의 BIOS 설정 항목 목록과 저장값을 대조합니다. 템플릿을 만든 뒤 새 BIOS 버전의 목록이 채집되었거나 그 보드의 최신 활성 펌웨어가 바뀌면, 저장값 중 일부가 목록에 없거나 허용되지 않는 값이 될 수 있습니다. 이런 값은 "레지스트리와 어긋난 저장 속성" 영역에 모여 표시됩니다.

주의

어긋난 값이 있는 템플릿을 쓰는 정의서는 그 보드의 서버에 할당할 때 잠김으로 표시되어 할당할 수 없습니다. 할당 창에는 "BIOS 템플릿 '명칭' 의 값이 보드 레지스트리(출처)와 어긋납니다" 뒤에 어긋난 항목이 이어진 사유가 표시됩니다.

어긋난 값을 정리하는 방법은 다음과 같습니다.

  1. 상세의 레지스트리와 어긋난 저장 속성 영역에서 어떤 항목이 어긋났는지 확인합니다.
  2. 수정 을 누릅니다. 어긋난 선택지 항목은 편집기에서 빈칸으로 보입니다.
  3. 그 항목을 다시 골라 저장합니다. 숫자 항목은 저장값이 그대로 보이므로 허용 범위 안의 값으로 고칩니다. 아무것도 고르지 않고 저장하면 그 항목은 템플릿에서 빠집니다. 목록에서 사라진 항목은 저장할 때 자동으로 빠집니다.
  4. 필요하면 서버 상세에서 정의서를 다시 할당합니다.

수정과 삭제

  • 상세의 수정 으로 명칭, 설명, 항목 값을 바꿀 수 있습니다. 저장하면 상세로 돌아갑니다. 대상 보드는 바꿀 수 없고 복제 기능도 없으므로, 다른 보드용 템플릿은 새로 작성합니다.
  • BIOS 자료가 없는 보드의 템플릿은 편집기를 열 수 없어 수정 이 눌리지 않습니다.
  • 템플릿에는 활성, 사용 중단 권고, 휴지통이 없습니다. 삭제 를 누르고 확인 창에서 삭제 를 한 번 더 누르면 곧바로 영구 삭제되며 되돌릴 수 없습니다.
  • 정의서가 쓰고 있는 템플릿은 삭제 가 눌리지 않습니다. 정의서를 삭제해도 계속 사용 중으로 남고, 그 정의서를 영구 삭제해야 템플릿을 삭제할 수 있습니다. 어느 정의서가 쓰고 있는지는 템플릿 화면에 표시되지 않습니다.
  • 템플릿이 남아 있는 메인보드 모델은 영구 삭제할 수 없습니다.
