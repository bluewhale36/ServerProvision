정의서 작성

세팅 정의서는 서버에 진행할 단계와 단계별 설정을 모은 문서입니다. 한 정의서를 여러 서버에 할당할 수 있으며, 서버는 할당받은 정의서의 단계를 차례로 진행합니다.

할당과 정의서의 관계

정의서를 서버에 할당하면 그 순간의 정의서 내용이 복사되어 서버의 할당에 고정됩니다. 그래서 이미 할당한 뒤에는 정의서를 수정, 비활성화, 삭제, 영구 삭제해도 그 서버가 진행할 내용은 바뀌지 않습니다. 고친 내용을 서버에 반영하려면 개시 전에 그 서버에 다시 할당합니다. 개시한 뒤에는 다시 할당할 수 없습니다.

단, 정의서가 고른 펌웨어, ISO, RAID 카드 같은 자원은 실행할 때 그 자원의 현재 상태로 다시 확인합니다. 최신 버전은 그때의 순위 1위 펌웨어로 정해지고, 직접 고른 펌웨어가 그사이 비활성화되었으면 그 업데이트를 건너뜁니다. 할당할 때 값이 복사되어 고정되는 것은 BIOS 세팅 템플릿의 값입니다.

목록

사이드바에서 프로비저닝세팅 정의서 를 엽니다. 표에는 #(정의서 ID), 정의서 명칭, 활성, 사용 중단, 포함 단계, 생성 일시가 표시되고, 행을 누르면 상세가 열립니다. 목록은 자동으로 갱신되지 않으므로 다른 사람이 만든 정의서를 보려면 새로 고칩니다.

조회 조건선택지
검색정의서 이름(부분 일치, 대소문자 무시)
활성전체, 활성, 비활성
사용 중단전체, 권고, 정상
포함 단계단계 종류 여러 개 선택 가능. 고른 단계를 모두 포함한 정의서만 표시

작성

  1. 새 정의서 작성 을 누릅니다.
  2. 정의서 명칭을 입력합니다.
  3. 단계 추가에서 넣을 단계의 버튼(+ 펌웨어 업데이트, + BIOS 설정, + RAID 구성, + OS 설치)을 누릅니다. 누른 단계의 설정 카드가 펼쳐집니다.
  4. 단계마다 설정을 입력합니다. 단계별 입력 칸은 단계 종류별 설정에서 설명합니다.
  5. 정의서 작성 을 누릅니다. 저장되면 정의서 상세가 열립니다.
  • 단계는 하나 이상 넣어야 합니다. 같은 종류의 단계는 한 번만 넣을 수 있으며, 넣은 종류의 버튼은 눌리지 않습니다.
  • 단계는 누른 순서와 상관없이 펌웨어 업데이트, BIOS 설정, RAID 구성, OS 설치 순서로 놓이고 그 순서로 실행됩니다.
  • 카드 머리의 단계 제거 는 확인 창 없이 그 단계를 뺍니다.
  • 입력 중 다른 화면으로 이동하거나 취소 를 누르면 입력한 내용이 경고 없이 사라집니다.
  • 비활성 자원은 선택지에 나오지 않습니다. 사용 중단이 권고된 자원을 고르면 "사용 중단 권고 자원" 확인 창이 열리며, 그래도 적용 을 누르면 선택이 유지됩니다. 고른 자원의 라벨 옆에는 사용 중단 배지가 붙습니다.
주의

Windows 는 RAID 구성 단계가 만든 OS 영역 볼륨에 설치됩니다. OS 설치 단계를 넣는다면 RAID 구성 단계도 함께 넣고, OS 영역이 될 RAID 묶음을 정해야 저장됩니다(OS 영역 볼륨). RAID 미구성 묶음은 저장은 되지만 실행하면 설치 단계에서 멈추므로 두지 않습니다.

명칭 규칙

정의서 명칭은 필수 입력이며 128자 이하입니다. 삭제되지 않은 다른 정의서와 같은 이름은 쓸 수 없어 "이미 사용 중인 정의서 명칭입니다" 오류가 표시됩니다. 삭제된 정의서의 이름은 다시 쓸 수 있습니다.

저장되지 않을 때

필요한 칸을 비웠거나 규칙에 맞지 않는 값이 있으면 저장되지 않습니다. 잘못된 칸은 그 칸 아래에 빨간 글자로 표시됩니다. 단계를 하나도 넣지 않았을 때와 명칭 중복처럼 특정 칸에 속하지 않는 오류는 폼 위쪽에 표시됩니다. 오류가 있는 카드는 자동으로 펼쳐지고, 서버가 거절한 경우에는 첫 오류 위치로 화면이 이동합니다.

OS 영역 볼륨

OS 설치 단계를 넣은 정의서는 RAID 구성 단계에서 OS 영역이 될 RAID 묶음을 정해야 저장됩니다. 묶음 하나의 역할을 OS 영역으로 정하거나, 역할을 우선순위에 따름으로 두고 볼륨 우선순위 행을 둡니다. 다음 경우에는 저장되지 않습니다.

  • RAID 구성 단계가 없거나 묶음이 하나도 없는 경우: OS 설치 카드에 "OS 설치 단계가 있으면 RAID 구성 단계에서 OS 영역 볼륨을 정해야 합니다." 가 빨간 글씨로 표시
  • OS 영역이 될 수 있는 묶음이 없는 경우: RAID 구성 카드에 안내 표시
  • OS 영역이 될 수 있는 묶음이 모두 RAID 미구성인 경우: "OS 영역 묶음이 RAID 미구성이면 설치 디스크를 정할 수 없습니다. OS 영역 묶음은 RAID 레벨을 골라야 합니다."

OS 영역 밖에 RAID 미구성 묶음이 있으면 저장은 되지만 "Windows 설치는 RAID 미구성 묶음이 있으면 설치 디스크를 정하지 못해 설치 단계에서 멈춥니다." 가 표시되고, 실행하면 그대로 멈춥니다. OS 를 설치하는 정의서에는 RAID 미구성 묶음을 두지 않습니다.

상세

상세의 기본 정보에는 사용 여부, 사용 중단 권고, 정의서 ID, 생성일시, 수정일시가 있고, 그 아래 단계마다 카드가 표시됩니다. 단계 카드 머리에는 다음 배지가 붙을 수 있습니다. 배지는 상세를 열 때마다 다시 판정됩니다.

배지조건조치
사용 중단 권고 자원 사용단계가 사용 중단 권고 자원을 사용. 마우스를 올리면 자원 이름 표시필요하면 다른 자원으로 수정
실행 시 생략 가능펌웨어 업데이트에서 메인보드를 직접 지정하고 최신 버전으로 두었는데 그 보드에 활성 펌웨어가 하나도 없는 경우펌웨어 등록 또는 활성화
실행 불가OS 설치 단계의 ISO 가 삭제되었거나 비활성인 경우ISO 활성화 또는 다른 ISO 로 수정

OS 설치 카드의 설치 이미지 옆에는 설치 소스와 대조한 결과가 표시됩니다. "설치 소스 미준비" 는 시스템 자산 화면에서 Windows 설치 소스를 준비하면 사라집니다. "설치 소스 누락" 이 보이면 정의서를 수정해 설치 이미지를 다시 고르고 저장합니다. Administrator 비밀번호는 값을 보여 주지 않고 설정됨 또는 미설정으로만 표시됩니다.

수정

상세의 수정 을 누르면 작성 화면과 같은 폼이 열립니다. 명칭과 단계 전부를 바꿀 수 있고, 변경 사항 저장 을 누르면 정의서 전체가 새 내용으로 바뀝니다. 할당 중이거나 개시한 서버가 있어도 수정할 수 있으며, 그 서버에는 반영되지 않습니다(할당과 정의서의 관계).

  • Administrator 비밀번호는 수정 화면에 값이 실리지 않고 기존 비밀번호 유지가 켜진 채 열립니다. 비밀번호를 바꾸려면 이 체크를 풀고 새 비밀번호를 입력합니다.
  • 저장 당시 고른 자원이 삭제되었거나 비활성화되었으면 그 칸이 선택에서 빠진 채 열리고, 경우에 따라 안내 문구가 표시됩니다. BIOS 세팅 템플릿, RAID 카드, 설치 이미지는 안내가 표시됩니다. 펌웨어 업데이트 단계의 메인보드와 펌웨어는 안내 없이 자동 감지와 최신 버전으로 돌아가고, BIOS 설정 단계의 메인보드, OS 버전, ISO 는 빈칸으로 열립니다. 저장하기 전에 각 칸을 확인합니다.

상태와 삭제

동작결과
비활성화새 할당과 다시 할당만 차단. 이미 할당된 서버와는 무관. 확인 창 없이 즉시 적용
사용 중단 권고할당은 계속 가능, 할당 창에서 경고 표시. 확인 창 없이 즉시 적용
삭제확인 창을 거쳐 삭제 상태로 변경. 할당 중인 정의서도 삭제 가능하며 이미 할당된 서버와는 무관. 목록과 할당 창에서 제외
복구확인 창 없이 즉시 복구, 삭제 전의 활성과 사용 중단 상태 유지. 같은 이름의 활성 정의서가 그사이 생겼으면 거절되므로 그 정의서의 이름을 바꾼 뒤 다시 복구
영구 삭제삭제된 정의서에서만 가능. 정의서 이름을 그대로 입력해야 버튼 활성화. 복구 불가

새 정의서는 활성 상태로 시작합니다. 삭제된 정의서는 휴지통 화면에 나오지 않고 자동으로 지워지지도 않으므로, 필요 없으면 정의서 상세에서 직접 영구 삭제합니다.
