계정과 로그인

관리 화면은 로그인한 사용자만 사용할 수 있습니다. 계정은 최고 관리자가 사용자 관리 화면에서 만들며, 계정이 없으면 최고 관리자에게 등록을 요청합니다.

권한 등급

계정에는 최고 관리자, 관리자, 사용자 세 가지 권한 등급이 있습니다. 높은 등급은 낮은 등급의 권한을 함께 가집니다.

권한 등급할 수 있는 일
사용자자원 관리, 세팅 정의서, 서버 프로비저닝, 운영 화면 전체 사용과 자신의 비밀번호 변경
관리자현재 사용자와 동일
최고 관리자관리자 권한 전체와 사용자 관리(계정 추가, 권한 등급 변경, 비활성화, 초기 비밀번호 지정)

사이드바의 사용자 관리 메뉴는 최고 관리자에게만 표시됩니다. 다른 등급의 계정으로 사용자 관리 화면 주소를 직접 열면 "접근 권한이 없습니다" 오류 화면이 표시됩니다.

로그인과 로그아웃

로그인 화면에서 아이디와 비밀번호를 입력하고 로그인 을 누릅니다. 아이디는 대소문자를 구분하지 않습니다. 비밀번호 칸 옆의 보기 를 누르면 입력한 비밀번호를 확인할 수 있습니다. 비밀번호 칸에 입력할 때 Caps Lock 이 켜져 있거나 한글이 들어가면 칸 아래에 경고가 표시됩니다.

로그인하면 게스트 서버 목록 화면(사이드바의 서버)이 열립니다. 로그인 전에 열려던 화면이 있었다면 그 화면으로 돌아갑니다.

아이디나 비밀번호가 틀리면 "아이디 또는 비밀번호가 올바르지 않습니다." 가 표시됩니다. 둘 중 어느 것이 틀렸는지는 알려 주지 않습니다. 비활성화된 계정으로 로그인해도 같은 문구가 표시됩니다. 맞는 비밀번호로도 로그인되지 않으면 최고 관리자에게 계정 상태를 확인합니다.

로그아웃하려면 사이드바 아래쪽 계정 영역의 로그아웃 을 누릅니다. 로그인 화면으로 돌아가고 "로그아웃했습니다." 가 표시됩니다. 계정 영역에는 로그인한 사용자의 이름과 아이디가 함께 표시됩니다.

로그인 상태가 끝났다는 안내

최고 관리자가 내 계정의 권한 등급을 바꾸거나, 계정을 비활성화하거나, 초기 비밀번호를 새로 지정하면 내 로그인 상태가 끝납니다. 화면이 바로 바뀌지는 않고, 다음에 화면을 이동하거나 버튼을 누를 때 로그인 화면으로 돌아가며 "계정 정보가 바뀌어 로그인 상태가 끝났습니다. 다시 로그인하십시오." 가 표시됩니다.

비밀번호 규칙

비밀번호는 다음 규칙을 따릅니다. 계정 추가, 초기 비밀번호 지정, 비밀번호 변경에 같은 규칙이 적용됩니다.

  • 길이: 8자 이상 72자 이하
  • 사용할 수 있는 문자: 영문 대문자와 소문자, 숫자, 특수기호 ! @ # $ % ^ & * ( ) - _ = + . , ?

문자 종류를 반드시 섞어 쓸 필요는 없습니다. 위 목록의 문자만 쓰면 됩니다. 한글과 공백, 목록에 없는 특수기호가 들어가면 받아들여지지 않습니다.

초기 비밀번호로 처음 로그인할 때

최고 관리자가 계정을 추가하거나 초기 비밀번호를 새로 지정한 계정은 다음 로그인에서 비밀번호를 바꿔야 합니다. 로그인하면 비밀번호 변경 화면이 열리고 "초기 비밀번호로 로그인했습니다. 계속하려면 비밀번호를 바꾸십시오." 가 표시됩니다. 비밀번호를 바꾸기 전에는 사이드바 메뉴가 흐리게 잠기고 "비밀번호를 바꾼 뒤 메뉴를 이용할 수 있습니다." 가 표시됩니다. 잠기지 않는 것은 비밀번호 변경, 사용 매뉴얼, 로그아웃입니다. 이 화면에는 취소 버튼이 없습니다.

비밀번호 변경

  1. 사이드바 계정 영역에서 비밀번호 변경 을 누릅니다.
  2. 현재 비밀번호, 새 비밀번호, 새 비밀번호 확인을 입력합니다. 새 비밀번호는 현재 비밀번호와 달라야 합니다.
  3. 비밀번호 변경 을 누릅니다. 게스트 서버 목록 화면으로 이동하고 "비밀번호를 바꿨습니다." 가 표시됩니다.

비밀번호를 잊었다면 최고 관리자에게 초기 비밀번호 지정을 요청합니다.

사용자 관리

최고 관리자만 쓸 수 있습니다. 사이드바 계정 영역의 사용자 관리 를 누르면 이 서버에 접근하는 모든 계정의 목록이 열립니다. 계정은 삭제하지 않고 비활성화합니다.

사용자 목록

표에는 이름, 아이디, 권한 등급, 상태, 등록 일시가 표시됩니다. 이름을 누르면 그 사용자의 상세가 열립니다. 이름 옆의 비밀번호 변경 대기 는 다음 로그인에서 비밀번호를 바꿔야 하는 계정이라는 뜻입니다.

사용자 추가

  1. 사용자 관리 화면에서 사용자 추가 를 누릅니다.
  2. 아이디와 이름을 입력합니다. 아이디는 사내 메일 주소의 @ 앞부분을 그대로 씁니다.
  3. 초기 비밀번호와 초기 비밀번호 확인을 입력합니다.
  4. 권한 등급에서 최고 관리자, 관리자, 사용자 중 하나를 고릅니다. 기본으로 선택된 등급은 없습니다.
  5. 사용자 등록 을 누릅니다. 새 사용자의 상세 화면이 열리고 "사용자 계정 hong.gildong 등록을 마쳤습니다. 첫 로그인에서 비밀번호 변경을 요구합니다." 처럼 등록한 아이디와 함께 안내가 표시됩니다.
  6. 정한 아이디와 초기 비밀번호를 사용자에게 전달합니다.

  • 본인 계정: 권한 등급 변경, 비활성화, 초기 비밀번호 지정 모두 불가. 다른 최고 관리자가 처리합니다. 본인 비밀번호는 비밀번호 변경으로 바꿉니다.
  • 비활성화된 계정: 초기 비밀번호 지정 불가. 먼저 활성화합니다. 권한 등급 변경은 비활성 계정에도 할 수 있습니다.
  • 이미 그 등급인 경우: 현재 등급은 선택지가 잠겨 있습니다.

본인 계정은 처리할 수 없으므로, 처리하는 최고 관리자 자신은 언제나 최고 관리자로 남습니다. 최고 관리자 두 사람이 동시에 서로의 권한을 낮추면 나중에 처리한 쪽이 "권한이 바뀌어 이 작업을 할 수 없습니다. 사용자 관리는 최고 관리자만 할 수 있습니다." 로 거절됩니다.
