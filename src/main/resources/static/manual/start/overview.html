PXE 서버 개요

ServerProvision 은 운영체제가 설치되지 않은 서버에 펌웨어 업데이트, BIOS 설정, RAID 구성, 운영체제 설치를 자동으로 진행하는 PXE 서버입니다. 같은 기종의 서버 여러 대를 같은 절차로 일관되게 준비하는 것이 목적입니다.

동작 방식

서버의 전원을 켜면 서버는 네트워크로 부팅(PXE 부팅)하면서 PXE 서버에 자신을 등록합니다. PXE 서버는 서버에 진단 리눅스를 부팅시켜 하드웨어 정보를 수집하고, 운영자가 할당한 세팅 정의서에 따라 단계를 차례로 진행합니다. 펌웨어 기록과 전원 제어는 서버의 BMC 를 통해 진행합니다.

운영자가 화면에서 하는 일은 세 가지입니다.

  1. 설치에 쓸 자원을 등록합니다.
  2. 서버에 진행할 단계를 세팅 정의서로 작성합니다.
  3. 등록된 서버에 정의서를 할당하고 프로비저닝을 개시한 뒤 진행을 지켜봅니다.

처음부터 끝까지의 과정은 처음 프로비저닝하기에서 따라 할 수 있습니다.

진행 단계

모든 서버는 부트스트래핑과 진단 리눅스를 거치고, 그 뒤로 정의서에 넣은 단계를 다음 순서로 진행합니다. 정의서에 넣지 않은 단계는 건너뜁니다.

부트스트래핑과 진단 리눅스는 서버가 등록되면 운영자의 조작 없이 진행됩니다. 그 뒤의 단계는 정의서를 할당하고 개시해야 진행됩니다.

BMC 표준 설정은 정의서의 BIOS 설정 단계에 포함됩니다. 따라서 BIOS 설정 단계를 넣지 않으면 BMC 표준 설정도 적용되지 않습니다. 고른 BIOS 세팅 템플릿 중 감지된 메인보드와 맞는 것이 없으면 BIOS 쪽만 건너뛰고 BMC 표준 설정은 그대로 진행합니다.

진행 화면에 OS 설정과 테스트라는 단계 이름이 보일 수 있지만, 현재 정의서 작성 화면에서 고를 수 없는 단계입니다.

관리 화면은 왼쪽 사이드바와 오른쪽 본문으로 나뉩니다. 사이드바의 메뉴는 다음과 같이 묶여 있습니다.

사이드바 맨 아래의 서류가방 모양 버튼은 배경 작업 목록을 엽니다. ISO 등록이나 자원 무결성 점검처럼 오래 걸리는 작업과 파일 업로드의 진행 상황과 결과를 여기서 확인합니다.

로그인하면 보통 게스트 서버 목록 화면(사이드바의 서버)이 열립니다. 계정에 관한 내용은 계정과 로그인에서 설명합니다.
