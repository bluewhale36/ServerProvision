선택 즉시 아래에 해당 모델의 BMC 펌웨어 등록 폼이 표시됩니다. 보드를 다시 바꿀 수 있습니다.
대상 메인보드 :
사람이 식별하기 쉬운 레이블.
같은 메인보드 안에서 버전은 유일해야 합니다.
서버 파일시스템상의 펌웨어 파일 경로. 디렉토리를 지정하면 업로드 파일명이 자동으로 이어 붙습니다. 아래에서 파일을 첨부하면 이 경로에 저장하고, 비우면 이 경로의 기존 파일을 그대로 등록합니다. 펌웨어 파일은 자기만의 디렉토리에 하나씩 두어야 합니다 — 다른 파일이 함께 있는 디렉토리는 거절됩니다.
경로는 255자까지 입력할 수 있습니다.
이 디렉토리에 저장: 현재 디렉토리를 펌웨어 파일 경로로 적용 — 파일 업로드 시 파일명이 자동 추가됩니다.
대상 경로의 상위(부모) 디렉토리가 없을 때 함께 생성합니다.
비워두면 파일 전송 없이 위 경로의 기존 파일을 등록합니다. 파일 형식(확장자)은 제한하지 않습니다.
취소
등록이 끝날 때까지 페이지를 떠나지 마십시오. 완료되면 자동으로 목록 페이지로 이동합니다.
