dnsmasq 관측이 구성되지 않았습니다.
pxe.dnsmasq.fragment-path 미설정. 설정하면 임대 목록이 여기 표시됩니다.
proxyDHCP 모드 — 이 서버는 임대를 만들지 않습니다.
IP 는 사내 DHCP 가 배정하고 이 서버는 부팅 위치만 답합니다. 게스트가 어떤 주소로 왔는지는 게스트 서버 목록의 등록 · 접촉 기록에서 봅니다.
자체 DHCP 만료 시각은 KST 기준입니다.
IP 주소 MAC 주소 만료(KST) 상태
기록된 임대가 없습니다.
