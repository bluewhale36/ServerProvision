PXE 네트워크 구성 (dnsmasq)

proxy DHCP
자체 DHCP 적용 완료 문법 거절 재기동 실패(이전 구성 복원) 복원 실패 미적용
dnsmasq 가 정지했습니다. 이전 구성 복원에도 실패했습니다. 서버에서 dnsmasq 를 복구해야 합니다.
마지막 적용이 실패해 이전 구성으로 서빙 중입니다. 값을 확인하고 다시 저장해야 합니다.
프로비저닝 허용 대역이 바뀌었습니다. 저장 및 적용을 다시 해야 dnsmasq 에 반영됩니다.
