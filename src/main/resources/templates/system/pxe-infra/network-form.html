PXE 네트워크 구성 (dnsmasq)

← PXE 인프라
자체 DHCP 적용됨 문법 거절 복원됨(재기동 실패) 복원 실패 미적용
저장된 구성이 현재 서빙 중인 dnsmasq 조각과 다릅니다 — 마지막 적용이 실패해 이전 구성이 서빙되고 있습니다. 아래 값을 확인하고 다시 저장하면 재적용을 시도합니다. 

        

    

    

        

            


                


                

                    
                    
                    
                    
모드는 dnsmasq 조각 한 벌을 만듭니다. 바꾸면 저장 · 적용 때 조각이 통째로 다시 써집니다.

                    

                


                

                    
                    
                    
네트워크 주소/prefix 형식(host bit 은 0). 자체 DHCP 는 이 대역에서 배정하고, proxyDHCP 는 이 대역의 PXE 요청에만 답합니다.

                    

                


                

                    
                    
                    
게스트가 ipxe.efi · boot.ipxe 를 받아올 이 서버의 TFTP 주소입니다. dnsmasq 는 이 주소가 붙은 NIC 에만 응답합니다(listen-address).

                    

                


                
                

                    proxyDHCP 모드에서는 IP · 라우터 · DNS · 임대를 사내 DHCP 가 배정합니다. 아래 필드는 쓰지 않으며 서버도 값을 저장하지 않습니다.
                

                

                    

                        
                        
                        

                    


                    

                        
                        
                        
시작 · 끝 모두 서브넷 경계 안이어야 하며 시작 ≤ 끝 이어야 합니다.

                        

                    


                    

                        
                        
                        

                    


                    

                        
                        
                        

                    


                    

                        
                        
                        
비워 두면 주 DNS 만 조각에 기록됩니다.

                        

                    


                    

                        
                        
                        
dnsmasq 는 임대 시간을 한 값으로 둡니다(최소 · 최대 구분 없음).
