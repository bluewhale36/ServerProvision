흐름 (F5 — 관리자가 사용자 관리에 들어갈 때)

관리자 GET /users
  → AuthorizationFilter
  → SuperAdminOnlyPolicy 거절 (ReasonedDenial)
  → AuthorizationDeniedException
  → ExceptionTranslationFilter (인증 사용자)
  → ReasonedAccessDeniedHandler (요청 속성 = 사유)
  → AccessDeniedHandlerImpl.sendError(403)
  → ERROR 디스패치 /error
  → ProvisionErrorAttributes (message = 사유)
  → 브라우저 error.html · XHR JSON

익명은 ExceptionTranslationFilter 가 진입점(로그인)으로 보낸다.
선례 : 게스트 체인 ProvisioningLanPolicy.Denied + GuestAccessDeniedHandler, 재렌더는 SignupSubmission.
