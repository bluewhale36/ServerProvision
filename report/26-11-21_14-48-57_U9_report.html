§1. 무엇을 만들었는가

세팅 정의서 상세의 [복제] 로 있는 정의서를 단계째 복사해 새 정의서를 만들고, 곧바로 새 정의서의 수정 화면으로 보냅니다. 단계에 든 비밀번호는 해시 그대로 복사하므로 다시 입력하지 않아도 됩니다.

계기 : E4-1-b-7 이 사용자 쉘 스크립트를 정의서 안에 담기로 정했습니다. 그러면 같은 스크립트를 다른 정의서에서 다시 쓰는 길은 정의서 복제뿐입니다. 그래서 사용자 지시로 b-7 구현 전에 이 슬라이스를 먼저 진행했습니다.

조작 : 정의서 id 9("HF34 CP5 A5 Rocky 9.5 RAID1") 상세에서 [복제] 를 눌렀습니다.

처리 : 머리 줄을 쓰는 54 화면 공통인 전역 style.css 를 고쳤습니다. .n-page-header 에 flex-wrap: wrap, .n-page-title 에 max-width: 100% · overflow-wrap: anywhere 를 더했고, flex-shrink 0 · keep-all 은 유지했습니다. 평소 화면은 그대로이고, 한 줄에 들어가지 않으면 오른쪽 요소가 다음 줄로 내려가며, 낱말이 폭보다 길 때만 낱말 안에서 끊습니다. 예전 '시스템 자 / 산'(F-6) 같은 회귀는 없습니다.
확인 : 정의서 상세 · 수정 · 목록, 서버 목록 · 상세, OS · 메인보드 · 그룹 목록 10 화면이 1440 · 1024 에서 넘침 0 입니다. 360 폭에서는 긴 이름이 없는 화면에도 같은 넘침이 있습니다. 앱 전체의 기존 문제이며 R21 이전 상태입니다.

증거 출처 : sbx-u9/cp7-title/overflow.json(10 URL · 1440 · 1024 · 360 한 번 실행, 넘친 경우만 기록하는 스캐너라 1440 · 1024 항목 없음 = 넘침 0, 기록된 9 건은 모두 360 의 앱 전체 기존 넘침).

2 · 'OS 영역 최소 용량 480 GB' 가 기본값인가

지적 : 사용자가 'OS 영역 최소 용량 480 GB' 가 기본값인지 묻고, 최소 용량을 전부 100 GB 로 해 달라고 했습니다.
원인 : 기본값이 아닙니다. 묶음 용량의 기본 방식은 '자동 탐지' 이고, 이때는 최소 용량이 나오지 않습니다. 480 은 '직접 지정' 칸의 placeholder 이고, 화면에 보인 값은 CP5 테스트 정의서의 데이터입니다.
처리 : setting-new.html 의 묶음 용량 placeholder 를 480 에서 100 으로 바꿨습니다. 샌드박스 u9 정의서 10 개의 묶음 용량도 SQL 로 480 GB 에서 100 GB 로 바꿨습니다(데이터만).
확인 : 정의서 상세에 "OS 영역 최소 용량 100 GB" 가 보이고, 작성 화면 placeholder 가 100 입니다.

3 · 수정 화면의 '상세로' 가 제목 위에 있음

지적 : 세팅 정의서 수정 화면의 '상세로' 가 제목 위에 있었습니다.
원인 : 수정 화면만 '상세로' 와 제목을 한 묶음으로 위아래로 쌓았습니다.
처리 : setting-edit.html 의 머리 줄을 다른 화면처럼 바꿨습니다. 제목은 왼쪽, '상세로' 는 오른쪽 끝(n-header-actions 안 n-back-link)입니다.
확인 : 짧은 이름과 긴 이름 모두 1440 · 1024 에서 넘침 0 입니다.

4 · 복제 뒤 '목록으로' 에서 강조가 안 됨

지적 : 복제 → '상세로' → '목록으로' 로 갈 때, 사본이 1 쪽이 아닌 곳에 있으면 목록 강조가 되지 않았습니다.
원인 : '목록으로' 는 이력 스택 맨 위 기록이 이 화면으로 들어온 기록일 때만 그 목록 쪽과 강조로 돌아갑니다. 사본 상세는 원본 상세에서 쌓인 기록과 경로가 달라 흐름이 끊긴 것으로 보고, 기본 목록으로 가면서 강조 키를 남기지 않았습니다. 옛 정렬(번호 오름차순)에서는 사본이 마지막 쪽에 있었습니다.
처리 : nav-stack.js 는 흐름이 끊겨도 '목록으로' 에 data-nav-self-key 가 있으면 기본 목록에서 그 행을 짚습니다. back-link.html 에 id 를 받는 backLinkFor(defaultHref, selfKey) 를 더했고, 기존 backLink 는 여기에 위임해 마크업은 한 곳입니다. 정의서 상세가 이것을 씁니다.
확인 : 브라우저에서 재현했습니다. 목록 2 쪽의 원본(id 5) → 상세 → 복제 → 사본(id 30) 수정 → 상세로 → 목록으로 순서로 가면, 기본 목록 1 쪽 맨 위에 id 30 이 있고 강조가 켜집니다.
