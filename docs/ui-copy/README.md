# 화면 문구 판정 기록

화면에 나오는 문구를 쓰임새와 심각도로 분류하고, 문구마다 어디에 어떤 모양으로 둘지 판정한 기록을 둔다. 이 판정이 화면 정보 위계 규약의 근거가 된다. 규약 자체는 `.claude/domain-conventions/` 에 두고, 이 디렉토리에는 규약을 정할 때 본 문구 목록과 판정 결과만 둔다.

## 파일

| 파일 | 내용 |
|---|---|
| `server-detail-copy.xlsx` | 게스트 서버 상세 화면의 판정표. 사용자가 판정을 입력하는 편집본이다 |
| `server-detail-copy.tsv` | 위 판정표의 판정 시트. 차이 비교용 원본이다 |
| `server-detail-labels.tsv` | 위 판정표의 라벨 시트. 필드 이름, 열 머리, 버튼 글자처럼 짧은 이름표다 |
| `server-detail-areas.html` | 판정표의 탭 칸, 자리 칸, 제안 자리 칸에 나오는 이름을 실제 화면 위에 번호 상자로 표시한 범례. 맨 위 이름 찾기 표에 판정표 칸 글자를 넣으면 그림 위치가 나온다. 지금 앱에 없는 제안 자리는 화면에 표시 띠를 끼워 넣어 찍었다 |

편집은 xlsx 에서 하고, 판정이 끝나면 tsv 를 xlsx 에서 다시 만든다. 두 파일이 어긋나면 xlsx 를 기준으로 한다.

## 판정표의 열

판정 시트의 한 행은 화면에 보일 수 있는 문구 하나다. 같은 문장이 여러 상태에서 나오면 한 행으로 두고, 표시 조건과 본 상황 칸에 그 상태들을 적는다.

| 열 | 뜻 |
|---|---|
| 현재 문구 | 화면에 보이는 꼴. 런타임 값은 `{서버 이름}` 같은 자리표시로, 상태에 따라 갈리는 문장은 `‖` 로 나눠 적었다 |
| 표시 조건 | 그 문구가 보이는 서버 상태. 코드에서 읽어 적었다 |
| 본 상황 | 샌드박스 화면 수집에서 그 문구가 보인 상황 번호. 상황 목록 시트가 번호마다 서버 상태와 스크린샷 위치를 적는다. 수집 화면에 없음은 그 상태를 만들지 못했거나 수집기가 읽지 못한 자리(tooltip 등)다 |
| 현재 모양 | 지금 화면의 글자 크기와 색, 판의 종류. CSS 클래스로 판정했다 |
| 세션 쓰임새, 세션 심각도, 세션 판정, 제안 자리 | 세션이 1차로 매긴 값. 정의는 분류 정의 시트에 있다 |
| 무게 어긋남 | 세션 심각도에 비해 현재 모양이 가벼우면 부족, 무거우면 과함. 묻힌 경고와 경보 피로를 찾는 데 쓴다 |
| 사용자 쓰임새, 사용자 심각도, 사용자 판정, 사용자 메모 | 사용자가 입력하는 칸. 비워 두면 세션 판정에 이견이 없다는 뜻으로 읽는다 |
| 출처 | 문구가 나오는 템플릿, 메시지 키, Java 메서드 |

출처 칸의 파일과 행 번호는 판정표를 만든 시점의 것이라 코드가 바뀌면 맞지 않을 수 있다. 판정표는 그 시점의 기록으로 보고, 다음 판정 때 목록을 다시 만든다.

## 갱신

화면 하나를 재편하는 단계가 끝나면 그 화면의 목록을 다시 뽑아 판정표를 새로 만든다. 이전 판정은 git 이력으로 남긴다.
