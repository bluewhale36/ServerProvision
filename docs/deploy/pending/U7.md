# U7 개시 IP 대역 판정

PR #106. 시스템 설정 화면과 프로비저닝 허용 대역을 더하고, 개시 전에 BMC 와 LAN 주소가 그 대역 안인지 판정한다.

## DDL 과 DML

- DDL 파일: `ddl/U7_system_setting.sql`
- 적용 시점: jar 앞. CREATE 권한이 필요하다.
- 하는 일: `system_setting` 테이블을 만든다. 설정 키 하나가 행 하나다.
- 확인 SQL: `SHOW CREATE TABLE system_setting;`
- DML 파일: `sql/U7_system_setting_seed.sql`
- 적용 시점: DDL 바로 뒤, jar 기동 전.
- 하는 일: 프로비저닝 허용 대역 초기값(10.1.1.0/24, 접근 권한 최고 관리자)을 넣는다. 같은 키가 있으면 건너뛴다.
- 확인 SQL: `SELECT setting_key, value_json, min_role FROM system_setting;`

DML 을 빠뜨리면 허용 대역이 비어 모든 서버의 개시가 막힌다.

## 사용자 결정

운영 프로비저닝 LAN 대역이 10.1.1.0/24 가 아니면 DML 의 값을 배포 전에 정하거나, 배포 뒤 시스템 설정 화면에서 바꾼다.
