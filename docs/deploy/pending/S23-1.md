# S23-1 OS 카탈로그

OSName 을 배포판과 메이저 단위 상수로 바꾼다. 이전할 곳이 없는 옛 행은 미지원 상수로 남고, S23-1-a 가 그 상수와 ENUM 의 옛 값을 지운다. 사용자 지시에 따라 미지원 상수는 배포 직후 없앤다.

## 점검 SQL

읽기 전용. 운영 DB 와 스테이징 DB 에서 배포 전에 돌린다.

```sql
-- ① os_metadata 를 (os_name, 메이저, is_deleted)별로 세고 분류
SELECT os_name,
       SUBSTRING_INDEX(os_version, '.', 1) AS major,
       is_deleted,
       CASE
         WHEN os_name = 'ROCKY_LINUX' AND SUBSTRING_INDEX(os_version, '.', 1) IN ('8', '9', '10') THEN '이전'
         WHEN os_name = 'WINDOWS_SERVER' AND TRIM(os_version) = '2025' THEN '이전'
         WHEN os_name IN ('ROCKY_LINUX', 'CENTOS', 'WINDOWS', 'WINDOWS_SERVER') THEN '미지원 유지'
         ELSE '그대로'
       END AS bucket,
       COUNT(*) AS cnt
  FROM os_metadata
 GROUP BY os_name, major, is_deleted, bucket
 ORDER BY os_name, major, is_deleted;

-- ② subprogram 을 분류(WINDOWS_SERVER 는 전부 WINDOWS_SERVER_2025 로 이전)
SELECT os_name,
       CASE
         WHEN os_name = 'WINDOWS_SERVER' THEN '이전'
         WHEN os_name IN ('ROCKY_LINUX', 'CENTOS', 'WINDOWS') THEN '미지원 유지'
         ELSE '그대로'
       END AS bucket,
       COUNT(*) AS cnt
  FROM subprogram
 GROUP BY os_name, bucket
 ORDER BY os_name;

-- ③ 미지원으로 남을 OS 를 참조하는 ISO 와 정의서 단계 수
WITH legacy_os AS (
  SELECT id FROM os_metadata
   WHERE (os_name = 'ROCKY_LINUX' AND SUBSTRING_INDEX(os_version, '.', 1) NOT IN ('8', '9', '10'))
      OR (os_name = 'WINDOWS_SERVER' AND TRIM(os_version) <> '2025')
      OR os_name IN ('CENTOS', 'WINDOWS')
)
SELECT 'iso' AS ref, COUNT(*) AS cnt FROM iso WHERE os_metadata_id IN (SELECT id FROM legacy_os)
UNION ALL
SELECT 'setting_process', COUNT(*) FROM setting_process
 WHERE process_type = 'OS_INSTALLATION'
   AND JSON_VALUE(payload_json, '$.osMetadataId') IN (SELECT id FROM legacy_os);
```

## 사용자 결정

① 과 ② 의 '미지원 유지' 합계로 배포 방식을 정한다.

| 합계 | 진행 |
|---|---|
| 모든 환경에서 0 | S23-1 과 S23-1-a 를 같은 배포에 싣는다. 미지원 상수가 남지 않는다 |
| 0 이 아님 | S23-1 을 배포한다. 운영자가 화면에서 그 OS, ISO, 드라이버를 휴지통에 넣고 영구 삭제한다(③ 의 정의서는 사용자가 정한다). 합계 0 을 확인한 뒤 S23-1-a 를 바로 병합하고 배포한다 |

## DDL 과 DML

- `ddl/S23-1_os_catalog.sql`: 적용 시점은 S23-1 jar 와 같은 순간. 두 컬럼의 ENUM 을 새 값과 옛 값의 합집합으로 넓히고, 이전할 수 있는 행만 옮긴다. 다시 적용해도 안전하다.
- `ddl/S23-1-a_os_catalog_legacy_drop.sql`: 적용 시점은 S23-1-a jar 와 같은 순간. 미지원 값이 남아 있으면 SIGNAL 로 멈추고, 없으면 ENUM 에서 옛 값을 지운다.
- 확인 SQL:

```sql
SHOW CREATE TABLE os_metadata;
SHOW CREATE TABLE subprogram;
SELECT os_name, COUNT(*) FROM os_metadata GROUP BY os_name;
```
