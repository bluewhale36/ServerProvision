# R17 RAID 칩 판별 데이터화

운영 배포(`d2d0307`, 2026-10-21)에 포함됐다. jar 는 적용했고 자산 교체만 확인이 남았다.

## 자산 교체

R17 에서 서버와 진단 리눅스 agent.sh 사이의 계약이 바뀌었다. 서버는 RAID 드라이버 목록만 보내고 칩 목록은 보내지 않는다. 옛 agent.sh 로는 RAID 채집과 RAID 단계가 모두 실패한다.

- 할 일: 시스템 자산 화면에서 AGENT 자산을 R17 이후 agent.sh 로 바꾼다. 관리자 로그인이 필요하므로 사용자가 한다.
- 확인 필요: 2026-10-21 배포 뒤 교체했는지 기록이 없다. 다음 배포 때 시스템 자산 화면에서 AGENT 의 등록 시각을 보고 확인한다.
- 교체 전에는 RAID 단계가 있는 프로비저닝을 시작하지 않는다. 진단 중인 게스트는 교체 뒤 재부팅한다.
