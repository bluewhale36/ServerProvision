## 점검 SQL

읽기 전용. 결과가 0 행이어야 아래 UNIQUE 를 만들 수 있다. 행이 나오면 어느 행을 남길지 사용자가 정한다.

```sql
SELECT vendor, model_name, COUNT(*) FROM board_model GROUP BY vendor, model_name HAVING COUNT(*) > 1;
```

## DDL 과 DML

- 파일: `ddl/HF26_board_integrity.sql`
- 적용 시점: jar 와 같은 순간.
- 하는 일: `board_model` 을 참조하는 외래 키 5 개를 ON DELETE RESTRICT 로 바꾸고, (vendor, model_name) 복합 UNIQUE 를 만든다. 외래 키 이름이 환경마다 달라서 스크립트가 (테이블, 참조 열)로 현재 키를 찾아 다시 만든다.
- 확인 SQL:

```sql
SHOW CREATE TABLE board_bios;
SHOW INDEX FROM board_model WHERE Key_name = 'uk_board_model_vendor_model_name';
```
