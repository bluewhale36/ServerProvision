## 점검 SQL

읽기 전용. HF32 부터 MPT IR 계열 카드는 RAID5 와 RAID6 를 만들 수 없는 레벨로 판정한다. 아래 결과에 나온 정의서는 실행 계획에서 RAID 단계가 보류되고, 수정 화면에서 저장이 막힌다.

```sql
-- 계열이 못 만드는 레벨이 남은 카드
SELECT id, vendor, model_name, supported_raid_levels FROM raid_card
WHERE chip_family = 'MPT_IR' AND (FIND_IN_SET('RAID5', supported_raid_levels) OR FIND_IN_SET('RAID6', supported_raid_levels));

-- 그 카드를 RAID5 나 RAID6 묶음으로 쓰는 정의서 단계
SELECT sp.id, sp.setting_definition_id, JSON_VALUE(sp.payload_json,'$.raidCardId') AS card,
       JSON_EXTRACT(sp.payload_json,'$.diskGroups[*].raidLevel') AS levels
FROM setting_process sp JOIN raid_card rc ON rc.id = JSON_VALUE(sp.payload_json,'$.raidCardId')
WHERE sp.process_type = 'RAID_CONFIGURATION' AND rc.chip_family = 'MPT_IR'
  AND (JSON_CONTAINS(JSON_EXTRACT(sp.payload_json,'$.diskGroups[*].raidLevel'), '"RAID5"')
    OR JSON_CONTAINS(JSON_EXTRACT(sp.payload_json,'$.diskGroups[*].raidLevel'), '"RAID6"'));
```

## 사용자 결정

두 번째 SQL 에 행이 나오면 그 정의서의 RAID 레벨을 고칠지, 정의서를 정리할지 사용자가 정한다.
