# HF24 v2 실기 확인: 부트 순서를 건드리지 않는 엔진으로 완주하는가

작성 2026-11-16 14:30 KST. HF24 v2(`plan/26-11-16_13-35-12_HF24_plan.html`)의 CP5 를 대신하는 실기 확인이다. 엔진은 이제 Once 무장, 재무장, BootOrder 정착을 하지 않는다.

## 준비

1. 대상은 손대지 않은 MS74-HB0 한 대다. iODD 는 뺀다.
2. BIOS 셋업 Boot 탭을 사진으로 남긴다. 순서가 공장 순서(Hard Disk, CD/DVD, USB, Network, UEFI AP)인지 확인한다.
3. HF24 v2 jar 를 spv-01 에 배포한다. `/etc/serverprovision/env` 에 `pxe-rearm-delay` 항목이 있으면 지운다(읽는 곳이 없어 남아도 해는 없다).
4. 정의서는 전 단계(굽기, 설정, RAID, Windows Server 2025)를 쓴다.

| 지점 | 정상 | 실패로 보는 것 |

| 첫 부팅 | PXE 로 들어와 등록, 진단 리눅스에서 인벤토리 보고 | 셸 |
| 굽기 뒤 전원 투입 | BIOS 가 스스로 재시작하더라도 PXE 로 돌아온다. 걸린 시간을 적는다 | 셸, 20 분 시한 실패 |
| 설정 적용 재시작 | PXE 로 돌아오고 값 확인이 통과한다 | 셸, 20 분 시한 실패 |
| RAID 구성 진입과 종료 재부팅 | PXE 로 돌아온다 | 셸 |
| Windows 착수 | PXE 로 와서 wimboot 를 받는다 | 셸 |
| Windows Setup 재부팅 | 디스크(Windows)로 부팅해 설치가 이어진다 | 셸 |
