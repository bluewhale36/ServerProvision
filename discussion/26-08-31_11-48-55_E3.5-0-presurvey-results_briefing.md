## 1. 카드 분별 (0-1 + 08-31 실측, 확정)

| | GIGABYTE CRA3338 | AVAGO MegaRAID 9361-8i |
|---|---|---|
| PCI 클래스 | `0107` Serial Attached SCSI | `0104` RAID bus controller |
| 칩 (Vendor:Device) | `1000:0097` (SAS3008) | `1000:005d` (SAS3108) |
| Subsystem (카드) | **`1458:3008`** | **`1000:9361`** |

분별 규칙: **Vendor:Device 로 칩 계열**(= 제어 계열 · 드라이버 · CLI), **Subsystem 으로 카드 상품**(= MA7 자원 `RaidCard.pciSubsystemId` 대조). `sas3ircu list` 도 같은 네 값을 낸다(SubSys Ven/Dev 열).

## 2. 제어 계열 (0-2, 확정)

| | CRA3338 (SAS3008 IR) | 9361-8i (SAS3108 MegaRAID) |
|---|---|---|
| 드라이버 | `mpt3sas` | `megaraid_sas` |
| CLI | `sas3ircu` (실측 04.00.00.00) | `storcli64` (실측 007.2508 — 서버의 `/usr/bin/storcli` 는 별도 등록한 alias, 사용자 확인 2026-08-31) |
| RAID 레벨 | 0 · 1 · 1E · 10, 볼륨 최대 2 | 0 · 1 · 5 · 6 · 00 · 10 · 50 · 60, Max VD 64 |
| 캐시 | 없음 | 2GB, 기본값 **WB · RA · strip 256KB** |
| 패스스루 | 볼륨 미소속 = 자동 | personality RAID(JBOD 전환 지원) · 현재 JBOD OFF · Capabilities `Enable JBOD: No` — E3.5-3 에서 재판정 |

- **Redfish 경로 종결**: 두 실서버 BMC 모두 `GET /redfish/v1/Systems/Self/Storage` → `Members@odata.count: 0`. GIGABYTE BMC 는 Storage 를 노출하지 않는다 — 집행은 리눅스 CLI 확정.
- 드라이버 가용: 진단 Alpine linux-lts(modloop) · RHEL 9 확인(0-2). **RHEL 10 도 실증** — 9361 서버가 Oracle Linux 10(el10_2, 커널 6.12)에서 정상 구동.
- 파서 `DiagnosticReportParser.kindOf` 는 이미 SAS 클래스를 RAID 로 분류(0-2 초판의 결함 지적은 정정됨).

## 3. sas3ircu CREATE 의 실기 제약 (08-31 실측, E3.5-3 입력)

`sas3ircu help create` 원문 기준(빌드 04.00.00.00):
- 크기는 **`MAX` 만 지원**("Size other than 'MAX' is not supported") — IR 볼륨 크기 지정 불가, 계획 산출은 IR 에서 항상 MAX 로 번역.
- 최소 디스크: RAID1 = 정확히 2 · RAID1E ≥ 3 · RAID0 ≥ 2 · **RAID10 ≥ 4**(가이드 문서의 "3~10" 보다 실기 help 가 우선).
- 볼륨 이름 = **영숫자(alpha-numeric) 문자열** — 하이픈 포함 `spv-r1-v1` 규약은 재검토 필요(예: `spvR1V1`). 결정은 E3.5-3 plan.

## 4. 리눅스 식별자 (D-8 실증)

두 카드 모두 볼륨이 `/dev/disk/by-id/wwn-0x…` 로 보인다 — `raid_volume` 의 리눅스 식별자 컬럼 성립.
- MegaRAID VD: WWN = `0x600605b0…`(카드 SAS Address `500605b00d18aa1e` 파생), lsblk MODEL = `MR9361-8i`.
- IR 볼륨: wwid `0097bf86d7e97988`(sas3ircu) → lsblk WWN `0x600508e0…86bf9700` 로 파생, MODEL = `Logical Volume`, TRAN = `sas`.
- 용량 계급 실증: 판매 표기 480GB SSD 를 CLI 가 `446.625 GB` 로 보고 — 매칭 1단계(표기 계급 스냅)의 기준 데이터.

## 5. 실물 구성 (파서 픽스처 · 매칭 예제 재료)

- **9361 서버**: PD 8 — SSD SATA 446.625GB(=480GB 표기) ×2(DG0) + HDD SAS 3.637TB(=4TB 표기) ×6(DG1). VD 2 — RAID1(SSD, OS 용) + RAID5(HDD ×6, 18.19TB). 기존 VD 이름 둘 다 빈 값(이름 규약 볼륨과 구분됨을 실증).
- **CRA 서버**: SAS HDD 4TB ×2 = IR RAID1 볼륨 1(ID 323 · Okay/Optimal), `RAID Support : Yes`(IR 펌웨어 확정), FW 15.00.00.00.

## 6. 집행 설계 결정 (0-3 종결, D-1~D-12 요약)
